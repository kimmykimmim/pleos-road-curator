# 0.46.0 창문 두리 시연과 발표자료 갱신

## 실행 조건

- 기준 커밋 `dfd22bb`, 앱 `0.46.0`, versionCode `48`.
- 설치되어 있던 0.45.0을 확인한 뒤 `:app:assembleDebug`로 빌드하고 debug APK를 덮어 설치했다. 설치 후 dumpsys로 versionCode 48을 확인했다.
- Pleos Connect v2.1.0 에뮬레이터 `emulator-5554`, 사용자 10, 정차 고정 경로 시연이다.
- 음성 듣기 화면을 먼저 별도로 촬영한 후, 보호자 메뉴에서 만남 횟수를 초기화했다. `rounds-start.xml`은 빈 map이며 가족 기록은 지우지 않았다.
- 시작 화면을 찍고 고정 경로를 한 번 선택했다. 전체 경로 녹화 중 시점 이동이나 응답 조작은 하지 않았다.
- 180초, 180초, 120초 제한과 비트레이트 8,000,000으로 기기 녹화를 나누고 각 제한 시간이 지난 뒤 가져왔다. 원본 화면과 저장 횟수는 약 12초 간격으로 수집했다.

## 두리 확인

- 시작 화면: 위쪽 하늘색 유리, 왼쪽 사이드미러 하나, 큰 두 눈이 보인다. 숯 배경에서 캐릭터 외곽과 표정이 구분된다.
- 음성 듣기: 롯데월드타워의 ‘내 생각엔… (직접 말하기)’ → ‘이야기할게’를 눌러 촬영했다. 질문 카드 머리의 눈이 호 모양으로 바뀌고 ‘듣고 있어. 그냥 말해도 돼.’ 문구가 표시된다. `listening-ui.xml`에도 이 문구가 있다.
- 듣기 화면은 초기화 전 두 번째 만남에서 촬영했다. 전체 경로는 그 후 초기화한 첫 번째 만남이므로 질문 내용이 다르다.
- 실제 발화로 인식 성공 여부를 시험하지 않았다. 듣는 표정과 화면 상태 확인을 음성 인식 정확도 확인으로 해석하지 않는다.

## 변경 범위와 한계

- 앱 소스, 색, 사진 크기와 내장 설명 영상은 변경하지 않았다.
- 직접 수행한 것은 debug 빌드·설치, 에뮬레이터 정차 시연, 직접 말하기 UI 조작과 화면·미디어 확인이다.
- 실제 차량 주행, 아이 음성 인식, 청취 품질, 실제 차량 패널의 낮/밤 가독성은 확인하지 않았다.
- 녹화는 무음이다. 일부 해설의 짧은 전환은 에뮬레이터 10배속 시연에서 관찰한 것이며 실제 주행 중 음성 길이를 검증한 결과가 아니다.
- 단위 검사 390개와 기기 검사 3종 통과는 구현 담당 인계 내용이며 이번 작업에서 재실행하지 않았다.

## 경로와 화면 확인 결과

- 롯데월드타워 → 63빌딩 → 여의도 → 숭례문 → 광화문 → 청진옥 순서로 마지막 마무리 카드까지 진행했다. t446에서 저장 횟수가 여섯 장소 모두 1인 것을 확인했다. 변화 기록은 `rounds-transitions.txt`에 있다.
- 여섯 질문 카드의 작은 창문 두리에서 하늘색 유리, 왼쪽 미러, 큰 눈을 확인했다. 해당 캡처에서 캐릭터와 글자의 겹침이나 잘림은 관찰하지 않았다.
- 각 질문 캡처의 원본은 순서대로 t014, t086, t170, t230, t302, t374다. 해설 확대는 t050, 완료 화면은 t446, 듣는 화면은 `listening-raw-2.png`다.
- t038은 관찰 단계로 확인되어 확대 해설 캡처에는 t050을 선택했다. 밝은 종이 위 하단 문장이 가려지지 않는다.
- 정지 캡처만으로 숨쉬기·눈 깜빡임·말할 때 입 움직임의 모든 상태를 독립 검증했다고 주장하지 않는다.

## 최종 파일 확인

- 전체 영상은 460.167초(약 7분 40초), 760×546, 12fps, 2,169,185바이트다. 455초 프레임에서도 청진옥 마무리 카드가 보인다.
- 전체 영상 디코딩 검사에서 오류가 없었다. 내장 브라우저에서도 오류 없이 재생되고 재생 시간이 증가하는 것을 확인했다.
- 발표자료에 연결한 캡처 9장이 모두 로딩됐다. 시작·듣는 중·확대 해설 배치는 `presentation-preview.png`에 남겼다.
- 발표자료의 미디어 파일 참조가 모두 존재하며 이전 0.45.0 미디어 참조는 남아 있지 않다.
- 기기 해상도 원본 영상은 `/tmp/curator46-raw/`에 보관했고, 저장소에는 앱 영역으로 자른 세 구간과 최종 영상을 남겼다.
- 요청한 캡처·전체 영상·발표자료 교체를 완료했다. 이번에 확인한 화면에서 새 두리의 잘림이나 배치 결함은 관찰하지 않았다.

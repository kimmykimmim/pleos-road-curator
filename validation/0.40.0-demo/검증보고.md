# 0.40.0 에뮬레이터 시연 점검

- 기기: Pleos Connect v2.1.0 `emulator-5554`, 앱 영역 1682×1210, 정차 시연 10배속.
- 저장소: `b34c766`. 기존 설치본과 기존 debug APK는 0.39.0이어서 0.40.0 debug를 새로 빌드해 설치했다. `dumpsys package`로 versionName 0.40.0, versionCode 42를 확인했다.
- `pm clear --user 10` 후 서울을 가로지르는 길을 선택하고, 롯데월드타워 → 63빌딩 → 여의도 → 숭례문 → 광화문 → 청진옥 순서를 자동 진행으로 한 번 확인했다. 화면은 12초 간격으로 캡처하고, `screenrecord --time-limit 180 --bit-rate 8000000` 세 구간을 제한 시간이 끝난 뒤 pull했다. `full-route.mp4`는 앱 영역 crop, 760px 축소, 12fps, CRF 32로 편집한 처음 약 401초다. `full-route-validation.mp4`는 약 499초까지 담은 검증본이다.

## 화면 관찰

- 여섯 장소 이름과 진행 순서, 여섯 칸 경로 막대가 화면상 이어졌다.
- 롯데월드타워, 63빌딩, 여의도, 숭례문, 광화문의 설명 사진은 화면상 해당 장소와 관련 있고, 작은 그림도 각 장소와 맞았다.
- 청진옥 작은 그림과 첫 설명 사진은 장소와 맞는다. 두 번째 설명 사진은 장소와 무관한 일반 해장국 사진이다. `scenes/sources.json`의 `recipe-bowl` 출처도 일반 `Haejangguk (hangover soup).jpg`다. 화면 문구 `3대를 건너온 해장국 한 그릇`은 그 사진이 청진옥 음식인 듯 보이게 한다. 해당 장소의 사진만 쓴다는 기준에 어긋난다. 증거: `cheongjinok.png`, `fresh-t372.png`.
- 표본 캡처에서 본문 글자 잘림과 경로 막대 파손은 보이지 않았다. 모든 애니메이션 프레임과 음성 자막을 전수 검사한 것은 아니다.
- 청진옥 첫 진행 이후 `fresh-t408.png`에서 `2번째 만남`이 표시됐다. 초기화 후 같은 경로를 한 번 진행한 기록이므로 재방문 표기의 원인 확인이 필요하다.

## 확인하지 못한 것

실제 차량 주행에서 5분 전 안내와 통과 판정, 아이의 실제 음성 입력 인식, 오디오 청취 품질. 자동 검사 382개 통과는 인계 문서의 기록이며 이 점검에서 재실행하지 않았다.

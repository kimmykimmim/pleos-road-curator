# 0.45.0 가독성 수정 재확인과 시연 갱신

## 실행 조건

- 기준 커밋 `03f168e`, 앱 `0.45.0`, versionCode `47`.
- 기기에 설치되어 있던 0.44.0을 확인한 뒤 `:app:assembleDebug`를 실행하고 debug APK를 덮어 설치했다. dumpsys로 0.45.0 / 47을 확인했다.
- Pleos Connect v2.1.0 에뮬레이터 `emulator-5554`, 사용자 10, 정차 고정 경로.
- 보호자 메뉴로 만남 횟수를 초기화하고 빈 `rounds-start.xml`을 확인했다. 가족 기록은 지우지 않았다.
- 앱 시작 화면을 촬영한 뒤 고정 경로를 한 번 선택했다. 녹화 중 시점 이동이나 응답 조작 없이 가상 시간 10배로 여섯 장소를 진행했다.
- 기기 녹화 제한을 180초, 180초, 120초로 나눴고 비트레이트는 8,000,000이다. 각 제한 시간이 지난 뒤 파일을 가져왔다.
- `tNNN.png`는 녹화 스크립트 시작 후 실제 경과 초이며, 약 12초 간격으로 화면과 저장 횟수를 남겼다. 정확한 명령 구간은 `capture-log.json`에 있다.

## 수정 재확인

### 해설 확대 하단 문장

`t038.png`와 `lotte-explain.png`에서 롯데월드타워의 “중심과 바깥 기둥이 함께 힘을 나눠요”가 밝은 종이 위에 선명하게 표시된다. 이전에 문장 위를 덮던 어두운 하단 그라데이션이 확대 해설에서 사라진 것을 확인했다. 사진 출처와 설명 아래 문장 모두 가려지지 않는다.

### 상단 배지

`start.png`에서 숯 바탕의 흰 상단 글자가 읽힌다. `lotte.png`에서는 밝은 회색 하늘 위에서도 경로 이름과 보호자 버튼이 어두운 배지 위에 표시되어, 이전의 흰 반투명 배지보다 선명하게 구분된다. `63building.png`의 밝은 푸른 하늘, `yeouido.png`의 회색 하늘, `sungnyemun.png`의 밝은 하늘 위에서도 경로 이름과 보호자 글자가 읽힌다. `gwanghwamun.png`의 푸른 하늘과 `cheongjinok.png`의 숯 바탕에서도 상단 글자를 확인했다.

### 짧게 전환되는 해설

구현 담당은 10배속 에뮬레이터 시연에서 음성이 없어 해설 종료가 빨리 전달되는 동작이라고 설명했다. 이번 기록도 에뮬레이터 화면과 무음 녹화이므로 실제 음성 길이나 실차 주행에서 머무는 시간을 검증한 결과로 표현하지 않는다. 이 사유는 발표자료 영상 설명에도 적었다.

## 변경 범위와 한계

- 발표자료의 시작 화면, 여섯 장소 질문 화면, 해설 확대 화면과 전체 경로 영상을 새 촬영본으로 갱신했다.
- 앱 소스와 내장 설명 영상은 수정하거나 재생성하지 않았다.
- 직접 실행한 것은 빌드, 설치, 에뮬레이터 정차 시연, 화면 및 미디어 파일 확인이다.
- 실제 차량 주행, 실제 아이 음성 인식, 청취 품질, 실제 차량 패널의 낮/밤 가독성은 검증하지 않았다.
- 발표자료의 자동 검사 390개 통과 표시는 구현 담당 인계 기록이며 이번 작업에서 단위·기기 검사를 재실행하지 않았다.

- 롯데월드타워 → 63빌딩 → 여의도 → 숭례문 → 광화문 → 청진옥 순서로 진행했다. t446에서 각 장소 저장값이 모두 1인 것을 확인했다. 변화 시점은 `rounds-transitions.txt`에 남겼다.
- 청진옥 마무리 카드는 `completion.png`와 원본 `t446.png`에 있다. 첫 방문 도중 다음 만남으로 표시되는 현상은 관찰하지 않았다.
- 발표자료 질문 캡처 여섯 장의 원본은 차례대로 t014, t086, t170, t230, t302, t374이며, 해설 확대는 t038, 시작 화면은 `start-raw.png`다.

## 최종 파일 확인

- 전체 경로 영상: 460.167초, 760×546, 12fps, 2,185,976바이트. 세 분할 녹화를 이어 붙이고 마무리 카드 뒤의 대기만 잘랐다. 455초 프레임에서도 청진옥 마무리 카드가 보인다.
- 최종 영상 전체 디코딩 검사에서 오류가 없었다.
- 내장 브라우저에서 발표자료의 새 캡처 8장이 모두 로딩되고, 영상이 오류 없이 재생되며 재생 시간이 7초 이상 증가하는 것을 확인했다. 시작/해설 확대 배치는 `presentation-preview.png`에 남겼다.
- 발표자료의 미디어 링크 파일이 모두 존재하고 `git diff --check`가 통과했다. 현재 발표자료에는 0.44.0 미디어 참조가 없다.
- 분할 녹화 사이의 짧은 명령 및 인코더 공백이 있으므로 프레임이 완전히 연속된 원본이라고 주장하지 않는다. 기기 해상도 원본은 임시 경로 `/tmp/curator45-raw/`에 두었고 저장소에는 앱 영역으로 자른 세 구간과 최종 영상을 남겼다.
- 요청한 재확인과 자료 교체를 완료했으며, 이번 확인에서 두 가독성 문제의 재발은 관찰되지 않았다.

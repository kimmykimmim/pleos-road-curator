# 역사 및 다양한 관심사 시연 영상

촬영일: 2026-11-14. 새 영상은 0.30.0(versionCode 32), 커밋 957dc61의 디버그 빌드를 Pleos 에뮬레이터에 설치하여 촬영했다.

| 파일 | 길이 | 내용 |
|---|---:|---|
| clip-16-history-flow.mp4 | 약 45초 | 숭례문의 질문 → 관찰 → 해설 → 아침 문지기. 연속 촬영본을 2배속으로 변환 |
| clip-17-palace-story.mp4 | 약 55초 | 광화문 뒤의 공간을 예상하고 궁궐 안내자 되기. 보호자 시점 이동 포함 |
| clip-18-living-history.mp4 | 약 55초 | 청진옥과 동네의 변화, 다음 사람에게 맛의 기억 전하기. 보호자 시점 이동 포함 |
| clip-19-variety.mp4 | 약 50초 | 과학 → 역사 → 궁궐 → 예술 → 생활사 → 역할 놀이 요약. 장면 발췌, 제목 추가 |

새 원본 세 개는 한국어, 역사 관심사, 자동 듣기 꺼짐으로 촬영했다. 직접 선택하는 화면 흐름을 보여 준다. 실제 아이의 발화나 실제 주행을 재현한 영상은 아니다. 전부 무음이다.

모음의 과학 장면은 기존 clip-01-photo, 예술 장면은 기존 clip-13-child-profile에서 발췌했다. 서로 다른 촬영본임을 페이지에 표시했다.

앱 영역만 잘라 760×546으로 축소했고, 모음에는 앱 화면을 가리지 않도록 위쪽에 80픽셀 제목 띠를 추가했다. 네 영상 모두 H.264 디코딩 확인, 브라우저에서 메타데이터 로딩과 재생 오류 없음 확인.

보기: ../../docs/다양한_관심사_시연.html. 기존 발표자료에도 네 영상을 추가했다. Drive 작업 폴더의 artifact/history-scenarios.html과 artifact/clips에도 복사해 두었다.

촬영 중 발표용 에뮬레이터의 장소별 만남 횟수는 UI로 초기화했다. 관심사는 촬영 후 기존 예술 설정으로 돌렸다. 앱 소스, 서명 APK, 커밋 및 원격 저장소는 변경하지 않았다.

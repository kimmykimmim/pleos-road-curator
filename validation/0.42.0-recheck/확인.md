# 0.42.0 독립 재확인

- 기준: c6f8905 (수정 ea4cb19 포함), emulator-5554, user 10.
- 작업 시작 시 기기와 debug APK는 0.41.0이었다. 기준 소스로 assembleDebug 후 설치했고 dumpsys package에서 0.42.0 / versionCode 44를 확인했다.
- 기기 저장값 2를 before-setup.xml에 보관했다. 앱을 force-stop한 뒤 청진옥 저장값만 1로 맞췄다(setup.xml). 앱을 실행하고 서울 경로 → 보호자 → 시점 이동 → 청진옥 통과 → 이어서 재생 순서로 조작했다.
- 역할 놀이부터 마무리까지 10초 간격으로 화면과 XML을 함께 저장했다.

판정: 요청한 동일 조건에서 표시 수정이 정상이다. 저장값 증가 후에도 같은 방문 번호를 유지했다. 추가 저장도 없었다. meeting-fixed.mp4는 이 전후를 담은 30초 검증 영상이다. 앱 코드는 수정하지 않았다.

기존 발표용 validation/0.41.0-demo/cheongjinok.mp4는 65초이며 마지막 장면은 역할 놀이다(published-tail.jpg). 마무리 카드가 없으므로 기존 409초 시연 모음은 그대로 사용한다. 과거 fresh-validation.mp4와 meeting-label-evidence.mp4는 오류 증거용으로만 남아 있고 발표자료에서는 참조하지 않는다.

발표자료 상단의 현재 앱 버전만 0.42.0으로, 자동 검사 수는 구현 담당 보고 기준 386개로 갱신했다. 녹화본의 0.40.0/0.41.0 출처 표시는 유지했다. 실제 차량 주행, 실제 아이 음성 인식과 오디오 품질은 확인하지 않았다. 단위 검사는 이번 담당이 재실행하지 않았다.

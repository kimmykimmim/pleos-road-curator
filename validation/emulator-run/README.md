# 에뮬레이터 실행 화면

2026-11-10, Android Automotive 에뮬레이터[API 33, arm64]에서 찍은 화면입니다.
Pleos 에뮬레이터가 아니므로 Pleos 내비와 음성 서비스는 없습니다.
`tools/emulator-demo-check.sh`로 다시 만들 수 있습니다.

## 시연 흐름

| 파일 | 내용 |
| --- | --- |
| `a-01-시작.png` | 앱 첫 화면. 상단 차량 상태바와 하단 공조 영역 사이만 사용 |
| `a-02-예고.png` | 01 먼저 상상해 보기. 롯데월드타워, 이 지점까지 약 5분 |
| `a-03-관찰.png` | 02 창밖에서 만나기 |
| `a-04-이야기.png` | 03 장소의 이야기. 해설과 설명 그림 |
| `a-05-역할놀이.png` | 04 오늘의 구조 설계자 |

처음 한 번 터치한 뒤로는 손대지 않았고 자동으로 넘어갔습니다.

## 음성 실패 복구

| 파일 | 내용 |
| --- | --- |
| `b-01-종료직전.png` | 03 해설을 말하는 중. 이 시점에 TTS 엔진을 강제 종료 |
| `b-02-복구후.png` | 멈추지 않고 04로 넘어감 |

완료 콜백도 오류 콜백도 오지 않는 상황입니다. 고치기 전에는 03에 그대로 멈췄습니다.

## 위치 권한과 서비스

| 파일 | 내용 |
| --- | --- |
| `c-01-시작시에는_묻지_않음.png` | 앱을 켜는 것만으로는 권한을 묻지 않음 |
| `c-02-시스템_권한창.png` | 실제 여행을 시작할 때만 뜨는 시스템 권한 창 |
| `c-03-위치설정_꺼짐_안내.png` | 차량 위치 설정이 꺼져 있을 때의 안내. 충돌 없음 |
| `c-04-실제내비_대기.png` | 허용 후 실제 내비 대기 화면 |
| `c-05-홈으로_나간_뒤.png` | 홈으로 나가도 전경 서비스가 유지됨 |

`c-04`의 `예고 가능한 장소 0곳 / 가까운 장소 0곳`은 이 에뮬레이터에 Pleos 내비
서비스가 없어서입니다. `logcat.txt`에 연결 실패 기록이 있습니다.

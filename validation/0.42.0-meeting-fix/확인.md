# 만남 횟수 표시 수정 확인 (0.42.0)

- 기기: Pleos Connect v2.1.0 `emulator-5554`. 기준 커밋 ea4cb19 기준 debug 설치.
- 조건: `round:cheongjinok` 저장값 1인 상태에서 보호자 메뉴의 시점 이동으로
  청진옥 통과를 선택하고 해설 → 역할 놀이 → 마무리 카드까지 진행.

| 시점 | 저장값 | 화면 칩 |
|---|---|---|
| 해설과 역할 놀이 | 1 | 2번째 만남 |
| 마무리 카드(저장 직후) | 2 | 2번째 만남 |

수정 전에는 마무리 카드에서 저장값이 2로 늘어나는 순간 같은 방문이
`3번째 만남`으로 표시됐다. 이제 방문이 시작될 때 고정한 번호를 쓰므로
한 방문 안에서 번호가 바뀌지 않는다. 다음 주행에서 비로소 3번째가 된다.

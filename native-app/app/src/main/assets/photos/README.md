# 장소 사진 넣는 곳

해설 단계에서 그림 대신 **실제 사진 두 장 이상을 겹쳐 넘기며** 변화를 보여 줍니다.
모래섬이던 여의도가 도시가 되는 것처럼, 달라졌다는 사실 자체가 중요한 장소에 씁니다.

## 지켜야 할 조건

- **출처 없는 사진은 화면에 나오지 않습니다.** `PhotoStage.source` 와 `license` 가
  둘 다 채워져야 쓰입니다. 코드가 막아 둡니다.
- 사진은 화면에 있는 동안 **연도와 출처를 함께** 보여 줍니다.
- **AI로 만든 이미지를 넣지 마세요.** 없던 모습을 지어내 아이에게 사실로 보여 주는
  일입니다. 이 앱이 가장 하지 말아야 할 것입니다.
- 사진이 없거나 한 장뿐이면 그 장소는 지금처럼 자체 제작 설명 그림을 씁니다.
  변화를 보여 주지 못하는 한 장은 그림보다 나을 것이 없기 때문입니다.

## 넣는 방법

1. 권리를 확인한 사진을 아래 이름으로 이 폴더에 둡니다. JPG 를 권장합니다.
2. `domain/PhotoStages.kt` 에서 해당 항목의 `source` 와 `license` 를 채웁니다.
   예: `source = "서울역사박물관"`, `license = "공공누리 제1유형"`
3. 빌드하면 그 장소의 해설에서 사진이 순서대로 넘어갑니다.

## 찾아볼 곳

공공누리로 공개된 자료가 있는지 먼저 확인하세요. 이용 조건은 자료마다 다르므로
반드시 개별 확인이 필요합니다.

- 서울기록원, 서울사진아카이브
- 서울역사박물관

- 국가기록원

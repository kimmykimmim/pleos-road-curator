아이가 창밖에서 **"어? 이거구나"** 하려면 도형이 아니라 그 장소의 실제 모습을 먼저 봐야
합니다. 그래서 질문과 관찰 단계에서 실제 사진을 보여 줍니다.

## 지켜야 할 조건

- **저작자와 라이선스가 적히지 않은 사진은 화면에 나오지 않습니다.** 코드가 막습니다.
  `PhotoStage.usable` 과 `PhotoStagesTest` 를 보세요.
- **AI로 만든 이미지를 넣지 마세요.** 없던 모습을 지어내 아이에게 사실로 보여 주는
  일입니다. 이 앱이 가장 하지 말아야 할 것입니다.
- 차에서 보이는 각도, 즉 길이나 강 건너에서 본 모습을 고르세요. 실내나 아주 가까이에서
  찍은 사진은 창밖에서 알아보는 데 도움이 되지 않습니다.

## 사진을 더 넣으려면

1. 재사용이 허용된 사진을 이 폴더에 둡니다.
2. `domain/PhotoStages.kt` 에 `asset`, `caption`, `author`, `license`, `page` 를 적습니다.
3. 한 장소에 **두 장 이상**을 시간 순서로 넣으면, 해설 단계에서 겹쳐 넘기며 변화를
   보여 줍니다. 모래섬이던 여의도가 도시가 되는 것 같은 이야기에 쓸 수 있습니다.
   한 장만 있으면 해설 단계는 원리를 설명하는 그림을 그대로 씁니다.

## 누끼 (배경을 지운 사진)

질문이 올라올 때 왼쪽 위에 뜨는 신문 스크랩은 **위 사진의 배경을 지운 것**입니다.
`tools/cutouts/make.sh` 가 macOS Vision 의 피사체 분리를 불러 만들고, 결과는
`assets/cutouts/` 에 들어갑니다. 그리는 것이 아니라 **빼는 것**입니다. 나온 픽셀은
전부 원본 사진의 픽셀입니다. 생성형 이미지는 쓰지 않습니다.

| 장소 | 누끼 | 비고 |
| --- | --- | --- |
| 롯데월드타워 | O | |
| 숭례문 | O | 문이 화면을 채우도록 먼저 잘라냄 |
| 광화문 | O | 넓게 두면 지나가던 자동차를 피사체로 잡음 |

누끼가 없는 두 곳은 기존 설명 그림을 그대로 씁니다. 아이에게 엉뚱한 그림을 보여 주는
것보다 정직한 도형이 낫습니다.

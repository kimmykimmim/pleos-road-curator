# 화면의 가장 큰 글자에만 쓰는 서체

- `Jua.ttf` — Jua, The Jua Project Authors, SIL Open Font License 1.1 (`Jua-OFL.txt`).
  https://fonts.google.com/specimen/Jua

한국어 둥근 디스플레이 서체입니다. 장소 이름과 시작 화면의 한 문장에만 씁니다.
나머지 글자는 시스템 산세리프 그대로입니다. 달리는 차에서 읽는 글은 중립적인 쪽이
낫고, 성격은 눈이 가장 먼저 닿는 한 군데에만 두는 편이 낫기 때문입니다.

OFL은 서체 파일과 함께 라이선스 전문을 배포할 것을 요구합니다. `Jua-OFL.txt`가 그것이고,
APK 안에 같이 들어갑니다. 서체 이름을 바꾸거나 단독으로 판매하지 않습니다.

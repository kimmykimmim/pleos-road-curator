# 풍경 친구 3D 자유 대화 확인 결과

- 확인일: 2026-11-09
- 대상: Pleos Connect v2.1.0, Android API 34, x86_64, 사용자 10
- 버전: 0.5.0, versionCode 5, 패키지 `dev.changbak.explorer`
- 차량 시스템 화면은 유지하고 기존 앱을 업데이트했습니다. 앱 데이터를 삭제하지 않았습니다.

## 확인한 흐름

1. `testDebugUnitTest assembleDebug assembleDebugAndroidTest` 빌드가 성공했습니다.
2. Android 단위 검사 88개가 통과했습니다. 실패, 오류, 생략은 0개입니다. 기존 81개와 새 비동기 답변 취소 검사 7개를 포함합니다.
3. `node --test server/local-companion.test.mjs`의 서버 모의 검사 16개가 통과했습니다. 입력 제한, 기억 전달, 세션 분리, 내용 검토, 오류 정보 차단, 시간 초과, 요청 취소와 호출 제한을 확인했습니다. 실제 OpenAI 호출은 하지 않았습니다.
4. 실제 에뮬레이터의 `FriendChatClient`를 검사용 로컬 서버에 연결했습니다. 연결 확인 → 한국어 문장과 친구 기억 전송 → 답변 해석 → 요청 도착 후 취소 → 늦은 콜백 억제 → 다음 대화 성공이 모두 PASS입니다. 메인 스레드에서 결과가 전달되는 것도 확인했습니다.
5. 검사용 서버는 종료했습니다. 승인된 `.env.local`에 키를 저장하고 실제 연결용 로컬 서버를 다시 시작했습니다. `127.0.0.1:8791/health`의 `ready`는 `true`이며 기본 모델은 `gpt-6.1-sol`입니다.
6. 앱 0.5.0을 업데이트 설치하고 MainActivity의 `topResumedActivity`를 확인했습니다. 시작 기록에서 3D 셰이더 컴파일과 첫 프레임 생성이 성공했고 해당 앱 기록에 치명적 예외가 없었습니다.
7. 실제 OpenAI 호출 세 번이 성공했습니다. 성인이 만든 가상 문장으로 목적지 전달 → 기분 표현 → 이전 목적지와 풍경 기억 질문 순서를 확인했습니다. 마지막 답변은 할머니 집에 간다고 했던 내용과 나뭇잎 귀의 원천을 모두 맞게 설명했습니다. 입력과 출력 검토를 포함한 운영 서버 경로로 확인했습니다.

## 연결 상태와 남은 확인

- **실제 OpenAI 연결과 세 번의 연속 대화 응답을 확인했습니다.** 키는 사용자가 승인한 프로젝트의 `.env.local`에만 저장했으며 앱, 소스 묶음과 출력에는 포함하지 않았습니다. 이번에 선택한 키의 유효기간은 생성 후 24시간입니다.
- `/health.ready`는 서버의 키 설정 유무만 뜻합니다. 키의 유효성, 이용 한도와 외부 응답 성공은 별도 실제 호출로 확인해야 합니다.
- 앱은 기본으로 기기 내 대화를 사용합니다. 보호자가 성인 가상 시연 조건을 확인하고 서버 연결 확인에 성공해야 AI 모드가 켜집니다. 마이크는 별도로 직접 켜야 합니다.
- 실제 13세 미만 아동의 개인정보 처리를 위한 ZDR 설정은 확인되지 않았습니다. 현재 연결은 성인의 가상 예시용입니다. `store:false`만으로 ZDR이 적용되는 것은 아닙니다.
- 실제 마이크 인식률, 스피커 소리, 모든 대화상자의 터치 흐름과 전체 차량 화면의 시각 검사는 완료하지 않았습니다. Windows 화면 도구를 다시 확인했지만 `failed to write kernel assets` 경로 오류가 반복되었습니다. 앱 안에서 AI 연결을 켜는 마지막 버튼은 사용자가 직접 눌러야 합니다.
- 실제 차량의 주행 전환과 탑승자 표시 위치는 검증하지 않았습니다. 앱은 차량의 사용 제한을 따르는 정차 시연 구성입니다.

## 중단과 저장

- 새 입력, 쉬기, 여행 마치기, 대화 끄기, 메뉴 열기, 새 여행, 앱의 배경 이동과 차량 제한에서 대기 중 요청을 무효화합니다.
- 같은 도착 화면에 머물러도 쉬기나 취소 후 옛 답변을 받지 않습니다. 마이크 재개 의도는 단순 청취 종료와 따로 관리합니다.
- 자유 대화는 최근 12개 메시지를 앱 메모리에서만 사용합니다. 새 여행과 앱의 배경 이동에서 비웁니다.
- 기존 풍경 종류, 특징 요약, 연결 부위와 별명 저장은 유지합니다. 음성 녹음과 대화 문장 전체를 파일로 저장하지 않습니다.
- 키는 앱에 포함되지 않습니다. `.env*`와 서버 실행 기록 폴더는 버전 관리 및 배포 묶음에서 제외합니다.

## 3D 확인 이력

- 0.4에서 동일한 렌더러를 화면 없는 EGL 버퍼에 그려 네 가지 친구 그림을 검사했습니다. 사용자 화면 캡처가 아닌 코드의 그리기 검사입니다.
- 고정된 자세에서 구름 몸에 나뭇잎 귀와 강물 꼬리를 더했을 때 14,204개 픽셀이 달라졌고 잎 색상은 5,502개 픽셀이었습니다. 그림도 직접 열어 확인했습니다.
- 0.5에서는 입체 도형 코드를 바꾸지 않았습니다. AI 응답의 분위기를 기존 표정에 연결하고 실제 앱의 첫 3D 프레임 생성까지 확인했습니다.

## 다시 검사하기

- 단위 검사와 빌드: `./gradlew.bat testDebugUnitTest assembleDebug assembleDebugAndroidTest`
- 서버 검사: `node --test server/local-companion.test.mjs`
- Android 연결 검사: 실제 서버를 먼저 종료한 뒤 `node server/transport-fixture.mjs`를 실행하고 `adb reverse tcp:8791 tcp:8791`을 적용합니다. 이어 `adb shell am instrument --user current -w -e check chat dev.changbak.explorer.test/dev.changbak.explorer.SceneRenderCheck`를 실행합니다. 종료 후 검사용 서버를 반드시 끕니다.
- 3D 코드 그리기 검사: 위 instrumentation 명령에서 `-e check chat`을 제외합니다.

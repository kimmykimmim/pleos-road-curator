# 풍경 친구 3D — Pleos 프로토타입 0.5

아이가 말한 풍경이 3D 친구의 몸, 귀, 꼬리와 여행 기억으로 쌓입니다. 친구는 여행 중에도 화면에 나타나고, 목적지와 기분을 주고받는 짧은 일상 대화를 시작합니다. Pleos의 운전 화면과 공조 바는 그대로 두고 앱 영역만 바꿨습니다.

## 자유 대화 연결

0.5에는 OpenAI를 사용하는 자유 대화 경로를 추가했습니다. 앱은 이 PC의 로컬 대화 서버에만 연결하며 API 키는 APK에 넣지 않습니다. 키가 없거나 연결되지 않았으면 기존 기기 내 대화를 사용할 수 있습니다. 실제 OpenAI 연결 검증 여부는 `VALIDATION.md`를 확인하세요.

1. PC에서 안전한 설정을 통해 프로젝트의 `.env.local`에 `OPENAI_API_KEY`를 저장합니다. 채팅, 소스 파일, 앱 화면에 키를 입력하지 않습니다.
2. 프로젝트 폴더에서 `node --env-file-if-exists=.env.local server/local-companion.mjs`로 대화 서버를 실행합니다.
3. 연결된 에뮬레이터에 `adb reverse tcp:8791 tcp:8791`을 적용합니다.
4. 앱의 **보호자 → AI 자유 대화 연결**에서 성인이 만든 예시로 시연하는 조건을 확인합니다.
5. 연결 확인 후 **이야기하기** 또는 **말 대신 입력해 보기**로 대화합니다.

흐름은 **말하기 → 기기에서 문자로 인식 → 현재 친구의 모습과 풍경 기억을 함께 전달 → 짧은 AI 답변 → 친구의 표정과 음성 → 다음 말 듣기**입니다. 풍경 관찰과 교정은 기존 앱에서 우선 처리하고, 일상 대화가 외부 AI로 전달됩니다. 카메라로 풍경을 보고 있다고 주장하거나 답변만으로 친구의 모습을 임의로 바꾸지 않도록 구성했습니다.

자유 대화 기록은 최근 12개 메시지만 현재 앱 메모리에서 유지하며 새 여행과 앱의 배경 이동 시 비웁니다. 서버는 대화 파일과 녹음을 남기지 않습니다. OpenAI 요청에는 `store:false`를 사용하지만 이것은 ZDR[API 데이터 보관을 하지 않는 계정 설정]과 다릅니다. **현재 연결은 성인이 만든 가상 예시용입니다. 실제 13세 미만 아동의 개인정보를 처리하려면 OpenAI의 ZDR 요구사항 확인이 먼저 필요합니다.**

## 바로 해보기

1. Pleos에서 **풍경 친구**를 엽니다.
2. 여행을 시작하고 **이야기하기**를 눌러 마이크 설명을 확인합니다.
3. 친구의 “오늘 어디 가?”에 답하거나 눈에 들어온 풍경을 말합니다.
4. 친구와 기분을 나누거나 생김새와 여행 기억을 물어봅니다.
5. **여행 마치기**를 누르면 친구가 이번 여행의 모습으로 남습니다. 이 화면에서도 대화를 다시 시작할 수 있습니다.

마이크 없이 확인하려면 **보호자 → 말 대신 입력해 보기**에서 아래 말을 한 번씩 입력해 보세요. 화면의 예시나 자유로운 문자 입력 모두 실제 음성과 같은 처리 경로를 사용합니다.

| 아이가 한 말 | 확인할 변화 |
| --- | --- |
| 구름이 동글동글해 | 동그란 몸과 구름 기억 |
| 나뭇잎이 살랑살랑 움직여 | 나뭇잎 귀가 더해지고 기존 몸 유지 |
| 강물이 반짝여 | 물빛 꼬리가 더해지고 기존 귀와 몸 유지 |
| 왜 꼬리가 반짝여? | 강물의 반짝임을 알려줬기 때문이라고 설명 |
| 그거 강이 아니라 바다였어 | 같은 기억의 원천이 바다로 교정됨 |
| 꼬리는 어디서 왔어? | 이후 답변에서는 바다를 언급 |
| 내가 뭘 봤지? | 아이가 알려준 풍경들을 짧게 회상 |
| 이름은 뭉치야 | 별명 변경 |
| 너 이름이 뭐야? | 저장된 별명으로 답변 |

위 순서는 기능 확인용 예시입니다. 실제 놀이는 정해진 재료나 순서 없이 아이가 알려주는 풍경에 따라 진행합니다.

일상 대화는 “할머니 집에 가” → “보고 싶어서 신나” → “너는 어때?”처럼 이어서 확인할 수 있습니다. 목적지와 기분은 현재 대화 중에만 사용하고 기기 저장소에 기록하지 않습니다.

## 관찰과 대화

- 새 관찰은 친구의 해당 부분과 기억에 반영합니다. 다른 풍경에서 만든 부분은 함께 남습니다.
- 질문만 했을 때는 새로운 풍경을 봤다고 기록하거나 모습을 바꾸지 않습니다.
- 친구는 각 부위의 가장 최근 원천 기억을 근거로 설명합니다.
- 기억을 정정하면 원천과 설명도 함께 고칩니다.
- 날개처럼 아직 없는 부분을 상상으로 더하는 경우 아이의 선택을 기다리고, 실제로 본 풍경과 구분합니다.
- 모르는 내용은 보거나 기억하는 척하지 않습니다.
- 연결을 끈 상태의 기기 내 대화는 목적지, 기분, 여행 기억과 친구의 모습에 관한 짧은 표현을 처리합니다. AI를 켠 경우에는 현재 친구의 기억을 바탕으로 더 자유로운 일상 대화를 요청합니다.

## 화면

- 여행 중에도 몸, 나뭇잎 귀, 물빛 꼬리, 날개와 색이 누적된 3D 캐릭터를 보여줍니다.
- 실제 입체 도형과 조명으로 그립니다. 입체처럼 보이는 평면 이미지를 붙인 방식이 아닙니다.
- 눈깜박임과 잔잔한 호흡을 표현하고, 음성 재생 중 입이 움직이며 듣는 동안 자세가 달라집니다.
- 입 움직임은 음성 재생 상태에 맞춘 연출입니다. 발음별 입 모양을 정확히 합성하는 기능은 아닙니다.
- 기억을 설명하는 대화는 여행 중과 마무리 화면 모두에서 가능합니다.
- 정해진 수집 개수, 점수, 제한 시간과 실패 판정은 없습니다.
- 친구는 준비된 입체 형태와 특징을 조합합니다. 실제 풍경 사진을 복원하거나 외부 이미지 생성 서비스에 요청하지 않습니다.

## 음성과 저장

- 기존 Pleos TTS/STT 3.3.1의 ON_DEVICE [기기 내부 처리] 방식을 유지합니다. AI 모드에서는 인식된 문자, 최근 대화, 친구의 모습과 풍경 기억이 로컬 서버를 통해 OpenAI로 전달됩니다. 녹음 파일은 보내지 않습니다.
- 마이크는 직접 켠 후에만 사용합니다. 짧은 안내 후 최소 600ms 뒤 듣기를 시작합니다.
- 무응답이나 인식 종료, 최대 25초 청취 후에는 조용히 듣기를 마칩니다. 다시 말할 때 **이야기하기**를 누릅니다.
- 쉬기, 여행 마치기, 앱의 배경 이동, 차량 사용 제한, 오디오 중단은 청취를 멈춥니다. AI 대기 중 대화를 끄거나 메뉴를 열고 화면을 떠나면 요청을 취소하고 늦게 도착한 답변도 재생하지 않습니다.
- 여행 마치기 직후에 마이크를 자동으로 다시 켜지 않습니다. 도착 후 대화는 직접 시작합니다.
- 저장하는 것은 풍경 종류, 특징 요약, 연결된 부위, 모습과 별명입니다. 녹음과 발화 문장 전체는 저장하지 않습니다.
- 기억은 최대 24개이며 현재 모습의 원천 기억은 우선 보존합니다.
- 앱을 다시 열면 이동 중 대화는 쉬는 상태로 복원합니다. 도착한 친구의 그림은 유지합니다.
- 이전 구름 버전의 친구가 있으면 모습을 옮깁니다. 이전 버전에서 기록하지 않은 풍경 원천을 새로 만들어 내지는 않습니다.
- 마지막 완료된 친구는 새 여행을 시작해도 보호자 메뉴에서 다시 볼 수 있습니다.

## 시연 범위

- 알려준 내용으로 작동하는 프로토타입입니다. 카메라, GPS, 실제 풍경 자동 인식과 시선 감지는 사용하지 않습니다.
- 풍경 해석은 짧은 한국어 표현과 대화 의도를 규칙으로 처리합니다. 인식하지 못한 문장은 임의의 관찰로 저장하지 않습니다.
- 자유 대화에는 OpenAI API 키와 사용 가능한 API 이용 한도가 필요합니다. 기본 모델은 `gpt-6.1-sol`이며 PC 환경변수 `OPENAI_MODEL`로 변경할 수 있습니다. 이미지 생성 API는 사용하지 않습니다.
- 로컬 서버는 `127.0.0.1:8791`에서만 실행합니다. 현재 구성은 개발 PC와 연결한 에뮬레이터 시연용이며 독립 실행하는 실제 차량 배포 구성이 아닙니다.
- Pleos 음성이 준비되지 않으면 보호자 메뉴의 문자 입력으로 시연할 수 있습니다.
- 차량의 주행 중 사용 제한을 따르는 정차 시연 버전입니다. 실제 주행 중 탑승자에게 제공하는 표시 위치와 정책은 별도 검토가 필요합니다.

## 개발 이어가기

Android Studio에서 이 폴더를 **Open**하고 동기화가 끝나면 **Pleos Connect v2.1.0 → Run**을 선택합니다.

- Android API 34, Build Tools 36.0.0
- AGP 9.1.0, Gradle 9.3.1, 이 PC의 빌드 JDK 21
- MainActivity.kt: 차량 앱 화면과 공통 입력 경로
- domain/TravelEngine.kt: 풍경 누적, 기억 교정, 대화
- domain/CompanionEngine.kt: 현재 대화의 목적지와 기분에 반응하는 일상 대화
- LandscapeFriend3DView.kt: 실제 입체 도형으로 조합하는 친구와 표정
- LandscapeFriendView.kt: 이전 여행 보관 그림
- TravelStore.kt: 기억, 친구와 마지막 여행 저장
- audio/VoiceGuide.kt: Pleos 음성 연결과 청취 중단
- network/FriendChatClient.kt: 키 없는 앱과 로컬 대화 서버 사이의 연결
- network/AsyncReplyGate.kt: 취소한 대화의 늦은 답변 차단
- server/local-companion.mjs: OpenAI 요청, 응답 형식, 제한 시간과 내용 검토

기존 CloudEngine과 CloudFriendView는 구름 표현 해석과 보관 그림에 재사용됩니다. 이전 미션 엔진은 현재 앱 화면에서 사용하지 않습니다.

# 창밖 합주

6~8세 아이를 위한 차량 동승자용 소리 놀이 프로토타입.

## 가로형 차량 화면

사용자가 제공한 Pleos 에뮬레이터 화면을 참고해 2026-11-08에 레이아웃을 변경했습니다.

- 왼쪽 차량 영역 → 가운데 풍경과 모은 소리 → 오른쪽 합주 조작의 세 영역으로 배치했습니다.
- 상단 상태 표시줄과 하단 검은 공조 및 앱 바를 재현하고, 앱은 흰색과 회색 바탕에 파란색을 사용합니다.
- 차량 상태와 공조 아이콘은 화면 배치 예시입니다. 실제 차량 정보 조회나 차량 조작 기능이 아닙니다.
- 작은 화면에서는 차량 예시 영역을 접고 합주 화면을 표시합니다.
- 차량 이미지는 내장 image_gen 도구로 생성한 투명 PNG입니다. 사용 프롬프트는 ASSET-PROMPT.txt, 파일은 dist/assets/vehicle.png에 있습니다.
- 이 변경에서는 브라우저 자동화가 설정에서 꺼져 있어 최종 화면의 브라우저 조작 검증을 수행하지 못했습니다. 이전 버전의 사용성 검사 결과와 구분해야 합니다.

## 아이의 흐름

1. 시작 → 창밖에서 눈에 들어오는 것을 관찰
2. 봤어 → 서로 다른 소리 두 개를 듣고 선택
3. 선택 즉시 합주 → 다시 창밖 관찰
4. 풍경이 바뀌었어 → 다른 느낌을 선택해 새 소리 추가
5. 끝내기 → 여행 음악 다시 듣기

자기 목소리는 선택 사항입니다. `내 소리로 할래`를 누르면 짧은 안내 뒤 마이크를 요청하고 최대 5초를 녹음합니다. `다 했어`로 일찍 끝낼 수 있으며, 취소나 오류 시 예시 소리로 이어집니다. 녹음한 소리는 의미를 해석하지 않고 원래 음색으로 합주합니다.

## 핵심 구현

- 아이 화면은 한 질문과 큰 행동 버튼 중심. 타이머 점수, 긴 설명, 믹서, 음성 명령 암기를 요구하지 않습니다.
- 띄엄띄엄 보이는 느낌은 짧은 타격음, 길게 이어지는 느낌은 긴 음, 통통 튀는 느낌은 위로 움직이는 음에 연결합니다. 정답을 판정하지 않습니다.
- 현재 풍경 소리가 크게, 직전 소리가 작게 이어집니다. 현재 소리 교체는 새 풍경으로 기록하지 않습니다.
- 부모 메뉴에 연습 그림, 음성 안내, 음량, 여행 목록, WAV 저장, 연구 근거를 모았습니다.
- 실제 창밖 모드가 기본입니다. 위치나 카메라로 풍경을 인식하지 않습니다. 그림 모드는 연습용이며 수동 선택입니다.
- 녹음 데이터는 브라우저 메모리에서만 처리하고 서버에 보내지 않습니다. 새로고침하거나 새 놀이를 시작하면 기록은 사라집니다.
- 최대 20개 풍경, 풍경마다 12초 분량으로 다시 듣거나 WAV로 저장합니다.
- 탭을 숨기거나 보호자 메뉴를 열면 음악과 녹음을 멈춥니다.

## 실행

빌드와 외부 JS 라이브러리가 없는 정적 웹 앱입니다.

```text
python -m http.server 8787 --bind 127.0.0.1 --directory dist
```

http://127.0.0.1:8787 에서 확인합니다. 녹음은 HTTPS 또는 localhost와 브라우저 마이크 권한이 필요합니다. 한국어 음성 안내는 기기의 음성 합성 지원에 따라 달라집니다. 버튼만으로도 핵심 흐름을 사용할 수 있습니다.

## 범위와 검증

최근 HCI 연구를 참고한 재설계입니다. 선택지 두 개와 구체적인 버튼 크기는 본 프로젝트의 설계 가설이며, 6~8세 아이 대상 사용성 효과를 아직 검증하지 않았습니다. 근거와 후속 관찰 계획은 RESEARCH.md에 정리했습니다.

이 결과물은 웹 프로토타입이며 Pleos용 APK가 아닙니다. 차량 실환경 테스트, 오디오 및 마이크 정책, 주행 중 허용 범위, 실제 화면 배치 검토가 별도로 필요합니다.

2026-11-08 확인: 390×844와 320×568 브라우저 화면, 관찰과 선택, 소리 교체, 일시정지, 보호자 메뉴, 연습 그림 선택, 녹음 준비 취소, 여행 다시 듣기를 점검했습니다. 320×568 선택 화면의 가로 및 세로 넘침은 없었습니다. 실제 마이크 장치 녹음과 아동 사용성 평가는 수행하지 않았습니다. 오디오 엔진의 녹음 종료 및 취소, 이전 소리를 보존하는 교체, 5초 음성 보존, 내보내기는 모의 환경에서 확인했습니다.

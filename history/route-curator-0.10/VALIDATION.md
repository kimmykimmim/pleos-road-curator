- 실제 아이의 목소리나 외부 AI 호출 없이 가상 문장으로 검사. 기존 API 키와 서버 설정 변경 없음.

## 사실 확인 자료

- 롯데월드타워: 롯데건설 초고층 구조 기술. 중심 코어, 큰 기둥, 아웃리거와 벨트트러스 연결을 고수준 원리로 표현. 수치 성능이나 실제 계산 결과를 제공하지 않음.
- 63빌딩: 포스코그룹 커튼월 설명. 뼈대와 유리 외벽의 역할 구분을 설명. 유리벽이 건물 전체의 하중을 지탱한다고 설명하지 않음.
- 여의도: 서울역사박물관과 서울기록원. 원래 있던 모래섬과 제방/매립 이후 도시 변화를 구분.
- 청진옥: 서울미래유산 기록에 근거한1937년 개업과3대 가업. 현재 운영자나 영업시간, 예약 또는 추천 정보를 제공하지 않음.
- 숭례문과 광화문: 기존 공식 국가유산청과 정책브리핑 자료.
- 각 원문 링크와 미디어 제작 기록은 README 및 앱 보호자 화면에 포함.

## 현재 한계

- 새 경험은 준비한 장소와 가상 ETA/통과 신호로 동작하는 정차 시연.
- 실제 내비게이션 연결은 기존 목적지 조회 코드까지만 유지. 전체 경로 자동 검색, 장소별 ETA/가시성/통과 시점 연결은 미구현.
- 운전자 주의 분산 제한 유지. 주행 중 승객용 화면과 자동 음성의 차량 정책 검증은 별도.
- 실제 전체 UI의 터치, 스크롤, 마이크와 스피커, VideoView에서의 전환 체감은 이번 턴에서 자동 UI 조작으로 검증하지 않음. MP4는 MediaMetadataRetriever로 실제 기기 디코딩 확인.
- 시스템 애니메이션 끄기 시 자동 영상 대신 그림. 수동 영상 재생 가능.
- 역할에서 선택하지 않으면 약20초 뒤 조용히 넘어가도록 구현했으며, 하지 않은 활동은 완료로 기록하지 않음. 타이머의 실제 터치 흐름은 미검증.
- 준비된 선택지와 연결된 음성 키워드는 그림을 바꾸며, 그 밖의 자유 발화로 임의의 새 구조나 그림을 생성하지는 않음.
- 외부 사진과 영상을 내려받아 재배포하지 않았으며 자체 제작한 원리 영상만 포함.

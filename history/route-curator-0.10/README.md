# 길 위의 큐레이터 0.10

Pleos 차량 UI 안에서 가는 길의 장소를 만나는 어린이 오디오 큐레이터 프로토타입입니다. 예고 → 창밖 관찰 → 짧은 해설과 시각 자료 → 역할 놀이 → 다음 풍경 순서로 이동 중의 경험을 구성했습니다. 핵심 놀이는 도착 전에 완결됩니다.

## 체험 경로

첫 화면에서 두 가상 경로 중 하나를 고릅니다.

- 한강의 과학 여행: 롯데월드타워 → 63빌딩 → 여의도.
- 도심의 오래된 이야기: 숭례문 → 광화문 → 청진옥.

경로의 시간은 정차 시연을 위해 10배로 흐르며 실제 내비게이션 도착 시간이 아닙니다. 처음 장소는 시작 후 약6초에 질문, 약33초에 관찰 안내, 약37초에 통과 해설이 나옵니다. 다음 명소는 12분의 가상 간격으로 배치했습니다. 앞의 해설이나 놀이가 진행 중이면 다음 장소가 끊어들지 않습니다. 놀이에 응답하지 않으면 약20초 후 조용히 듣기만 한 장면으로 넘어갑니다. 아이가 선택하지 않은 활동을 수행한 것으로 기록하지 않습니다.

빠르게 보려면 보호자 → 시점 이동해서 확인 → 원하는 장소의 통과를 고릅니다. 해당 장소의 5분 전 예고부터 새로 준비한 뒤 통과 신호를 넣는 독립 시연입니다. 기존의 진행 중인 여행과 함께 이어지는 위치 변경 기능은 아닙니다.

해설이 끝나면 역할 놀이가 이어집니다. 음성을 재생할 수 없는 환경에서는 ‘해설을 글로 보기’ 또는 ‘이제 내가 해 볼래!’로 진행할 수 있습니다. 역할은 버튼이나 내 말로 선택할 수 있습니다. 화면에 없는 자유로운 문장은 ‘내 말로 만든 장면’으로 받아주며 새 과학 모형을 생성하지는 않습니다.

## 장소별 내용과 행동

| 장소 | 해설의 중심 | 아이가 하는 일 |
| --- | --- | --- |
| 롯데월드타워 | 중심 몸통, 바깥 기둥, 아웃리거와 벨트트러스의 연결 | 몸통과 기둥 또는 바깥 기둥끼리 연결한 부분 강조 |
| 63빌딩 | 하중을 지탱하는 뼈대와 커튼월 유리 외벽의 역할 구분 | 뼈대를 드러내거나 유리 겉옷 다시 입히기 |
| 여의도 | 원래 있던 모래섬, 제방과 매립, 도시화 | 미래의 섬에 나무 그늘이나 새의 쉼터 더하기 |
| 숭례문 | 밤에 닫고 아침에 열던 도시의 문 | 아침 인사를 고르면 모형 속 문 열기 |
| 광화문 | 경복궁의 정문 | 궁궐 안내자가 되어 손님 맞기 |
| 청진옥 | 서울미래유산에 기록된1937년 개업과3대 가업 | 맛의 기억이나 따뜻한 인사를 다음 사람에게 전하기 |

사실 해설 뒤에 ‘이제 우리가 상상해 보자’라고 알립니다. 아이가 고르는 장면은 상상 놀이이며 실제 구조 설계, 실제 도시 계획이나 실제 조리법으로 제시하지 않습니다. 맞음/틀림 비교나 정답 점수는 제공하지 않습니다.

## 그림과 영상

- 자체 제작한 설명용 그림과 6초짜리 무음 MP45개를 앱에 포함했습니다. 인터넷 연결 없이 재생합니다.
- 롯데월드타워, 유리 외벽, 여의도, 가업 전달, 성문에 각기 다른 움직임이 있습니다.
- 설명 단계에서 영상이 재생되고, ‘짧은 원리 영상 다시 보기’로 다시 볼 수 있습니다.
- 영상은 소리를 내거나 오디오 포커스를 요청하지 않습니다. 앱 음성 안내와 경쟁하지 않습니다.
- 음성과 역할 놀이는 화면을 계속 보지 않아도 선택하고 들을 수 있도록 구성했습니다. 자동으로 마이크를 켜지는 않습니다.
- 시스템 애니메이션을 끄면 자동 영상 대신 그림을 표시하며 사용자가 직접 재생할 수 있습니다.
- 그림, 영상, 선택 결과는 정확한 구조 도면이나 수치 시뮬레이션, 실사, 역사 항공사진이 아닌 원리를 단순화한 모형입니다.
- 캐릭터 생성과 기존 비교 질문 화면은 새 흐름에서 사용하지 않습니다.

## 실제 차량 연동 범위

차량의 주행 화면과 공조 UI를 유지하고 앱 영역만 사용합니다. 기존 운전자 주의 분산 제한을 유지하며 현재 정차 시연용입니다. 실제 주행 중 승객용 화면과 음성 제공에 대한 차량 정책 검증은 별도입니다.

실제 NaviHelper3.0.5 SDK의 목적지 조회 연결은 유지합니다. **실제 전체 경로에서 모든 명소를 자동 검색하고 지점별 ETA와 통과 시점을 계산하는 기능은 아직 연결하지 않았습니다.** 체험은 준비된 장소와 가상 ETA를 사용합니다. 목적지 ETA나 주변 직선거리를 명소 도착 시간으로 대체하지 않습니다. 실제 시야 감지나 카메라 인식도 하지 않습니다. 골목 안 가게는 보이지 않을 수 있다고 안내합니다.

## 저장과 음성

새 시연 기억은 별도 route_curator_v1에 장소 ID, 선택한 예상, 관찰 여부, 수행한 역할 이름으로 저장합니다. 자유 발화 원문과 음성, 위치 좌표는 저장하지 않습니다. 외부 AI는 호출하지 않으며 기존 API 키와 중계 서버도 변경하지 않았습니다. 구름 버전 저장 데이터는 그대로 보존합니다.

## 주요 코드

- domain/CuratorContent.kt: 여섯 장소의 검토한 해설, 출처, 역할 선택지와 두 시연 경로.
- domain/RouteCurator.kt: 위치 신호, 예고, 해설과 역할 놀이의 순서 및 중복 방지.
- CuratorMediaArt.kt: 원리 그림과 영상에 사용하는 자체 제작 벡터 그림.
- CuratorMediaPanel.kt: 번들 MP4 재생, 음성 포커스 미요청, 수명 관리.
- CuratorSceneView.kt: 선택에 따른 그림과 700ms 교차 페이드.
- MainActivity.kt: 새 시연, 음성 입력, 화면과 보호자 기능.
- app/src/main/res/raw/curator_*.mp4: 앱에 포함한 6초 무음 영상.

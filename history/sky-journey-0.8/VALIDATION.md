## 현재 확인 범위

- 실제 속도 콜백은 권한 허용 후 연결하도록 구현했으나 실차에서 권한과 데이터 수신은 미검증.
- 기존 운전자 주의 분산 제한 유지. 현재 정차 시연용이며 주행 중 승객 사용을 보장하지 않음.
- 길은 이동량 기반의 상상 경로. GPS, 실제 회전 방향, 자동 도착 또는 자동 터널 인식을 구현하지 않음.
- 터널과 풍경은 사용자의 말로 알려줌. 운행 마치기도 사용자가 직접 실행.
- 터치, 실제 마이크와 스피커, 전체 차량 UI의 배치는 이번 턴에서 자동 조작으로 검증하지 않음.
- 시연 상태는 실제 세션에 저장하지 않는 별도 흐름. 원래 여행을 지우지 않음.
- API 키와 중계 서버는 변경하지 않았고 이번 턴에서는 외부 AI를 호출하지 않음. 아동 실제 데이터에 대한 배포 검토는 여전히 미완료.

# 구름 친구 0.8 — 우리 차가 만드는 하늘길

Pleos 차량 UI 안에서 사용하는 정차 시연용 Android 프로토타입입니다. 기존 구름 친구 생성과 대화, 부드러운 3D 전환을 유지하고 차량 이동량과 아이의 관찰로 하늘길을 만듭니다.

## 직접 체험하기

1. 보호자 → 차량 이동 / 시연 → 이동 시연 시작.
2. 보호자 → 말 대신 입력해 보기에서 “저 구름 토끼 같아”. 음성 사용도 기존과 같습니다.
3. “조금 더 달리기”를 누르면 가상 이동 180m가 추가되며 길이 이어집니다. 아이에게 점수나 속도 경쟁을 제시하지 않습니다.
4. “나무가 엄청 많아”, “커다란 다리를 건너고 있어”라고 말하거나 입력하면 해당 구간에 숲과 다리가 생깁니다. 순서는 자유롭습니다.
5. “터널에 들어왔어” → 작은 빛과 어두운 분위기. “터널에서 나왔어” → 밝기가 다시 부드럽게 돌아옵니다.
6. 여행 마치기 → 길이 약 0.9초 동안 접히며 하늘섬이 됩니다. 친구와 발견한 풍경이 함께 남습니다.
7. 시연 끝내기를 누르면 이전 여행으로 돌아옵니다. 시연 상태는 실제 여행 저장 공간에 쓰지 않습니다.

새 여행과 이전 여행 보기는 기존 보호자 메뉴에서 사용할 수 있습니다. 일상 대화와 구름을 친구 또는 배경으로 만드는 선택도 유지합니다.

## 실제 차량 연결과 현재 한계

보호자 → 차량 이동 / 시연 → 차량 이동 연결에서 속도 읽기 권한을 요청합니다. CarPropertyManager의 PERF_VEHICLE_SPEED 콜백을 받아 연속된 신선한 샘플 사이의 이동량만 적분합니다. 3초 이상 끊긴 구간, 오류, 비정상 값은 이동으로 만들지 않습니다. 앱이 배경으로 가면 구독을 해제합니다.

- 이동량이 만드는 추상적인 하늘길입니다. 실제 도로 모양, 회전 방향, GPS 좌표 또는 목적지는 수집하거나 표현하지 않습니다.
- 실차의 권한 허용과 속도 콜백 수신은 아직 현장 검증하지 않았습니다. 지원 여부와 연결 상태는 보호자 화면에서 확인합니다.
- 기존 운전자 주의 분산 제한을 유지합니다. 이동 중 중앙 화면을 해제하지 않으며, 현재 체험은 정차 상태의 별도 이동 시연으로 확인합니다. 실제 승객용 운행 경험은 해당 화면과 차량 정책 확인이 추가로 필요합니다.
- 터널과 풍경은 아이가 알려준 말로 반응합니다. 카메라 인식이나 자동 터널 감지는 없습니다.
- 운행 완료는 “여행 마치기” 또는 “도착했어”로 직접 알립니다. 자동 도착 감지는 없습니다.
- 총 이동량, 차량/시연 출처, 풍경 종류와 그 이동 구간을 저장합니다. 정확한 위치와 음성 녹음, 원문 전체는 저장하지 않습니다.
- 반복 관찰은 가까운 같은 구간에서 중복되지 않으며 풍경은 최대 32개로 유지합니다.

## 전환

3D 화면을 재생성하지 않고 구름 생성, 위치와 얼굴을 약 820ms 동안 연결합니다. 하늘길의 확장과 섬 전환, 터널 밝기는 약 900ms 동안 변화합니다. 시스템의 애니메이션 끄기 설정을 따릅니다.

## 대화 연결

기존 PC 중계 서버와 API 연결 방식을 변경하지 않았습니다. 보호자 → AI 자유 대화 연결에서 성인 또는 가상 입력 시연을 활성화해야 합니다. API 키는 앱과 배포 압축 파일에 포함하지 않습니다. 서버 실행과 설정은 [server/README.md](server/README.md)를 참고하세요. 실제 아동 데이터 사용을 위한 검토는 완료되지 않았습니다.

## 주요 파일

- domain/SkyJourney.kt: 이동량, 관찰 구간, 터널 상태와 완료 처리.
- VehicleJourneySource.kt: 차량 속도 읽기와 구독 수명 관리.
- JourneySceneView.kt: 하늘길, 풍경, 빛과 섬 전환.
- CloudWorldStore.kt: 구름과 여행의 로컬 저장 및 v0.6 이후 데이터 호환.
- MainActivity.kt: 차량 UI 내부의 화면, 음성 및 별도 시연 모드.

검증 결과는 VALIDATION.md에 기록합니다.

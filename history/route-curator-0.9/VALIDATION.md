## 구체적으로 검증한 동작

- 301초에는 질문하지 않고300초 이하에 질문. 최종 목적지 대신 지점별 ETA 사용.
- 반복되거나 오래된 위치 이벤트는 질문과 해설을 재생하지 않음.
- 먼저 답하지 않아도 지점 통과 시 해설 시작.
- 멀리서 ‘봤어’를 입력해도 관찰로 인정하지 않음.
- ‘안 보여’는 NOT_SEEN으로 유지하면서 통과 후 해설 제공.
- 해설 뒤 예상과 비교 결과를 같은 장소 기억에 유지. 모름도 허용하며 점수 없음.
- 경로에서 빠진 예정 질문 취소. 이미 설명하는 장소는 다음 장소가 끊지 않음.
- 지원하지 않는 장소에는 내용을 만들어내지 않음.
- 완료한 여행은 반복 위치 신호로 재시작하지 않음.

## 실제 연동과 시연 구분

- 전체 경험은 숭례문/광화문을 넣은 가상 경로, 가상 지점별 ETA와 통과 신호로 동작.
- 공식 SDK 실제 목적지 조회와 변경/취소 콜백 연결 코드는 구현했으나 이번 턴에서 실제 목적지 응답 수신은 확인하지 않음.
- 전체 활성 경로 추출, 경로 위 명소 자동 검색, 명소별 ETA, 관찰 구간과 실제 통과 신호 변환은 미구현.
- 지도 가까이 있다는 이유로 보이는 명소라고 판단하지 않음. 시연의 observable은 제공된 시연 데이터.
- 현재 정차 시연용. 주행 중 승객 화면과 음성 정책 검증은 미완료.
- 예전 구름 구현은 CloudLegacyActivity와 소스에 보존하되 실행 화면에서 제거. 기존 저장 공간은 건드리지 않음.
- 새 실행 화면은 외부 AI나 중계 서버를 호출하지 않으며 API 키 변경 없음.
- 새 시연 기억은 별도 route_curator_v1에만 저장. 자유 발화는 실행 중에만 표시하고 저장하지 않음.

# 길 위의 큐레이터 0.9

차량 내비게이션 경로에서 만나는 역사 장소를 어린이에게 오디오 큐레이터 방식으로 소개하는 정차 시연용 프로토타입입니다. 이전 구름 친구 화면을 새 큐레이터 화면으로 교체했습니다. 기존 구름 데이터는 삭제하거나 변환하지 않습니다.

## 핵심 흐름

1. 명소를 지나기 약5분 전: 답을 알려주기 전에 열린 질문을 합니다.
2. 아이는 보기 중 하나를 고르거나 자신의 말로 예상합니다. 답하지 않아도 진행합니다.
3. 약30초 전: 창밖에서 살펴볼 특징을 안내합니다. 안 보이면 넘어갑니다.
4. 해당 지점을 통과하는 위치 신호가 오거나, 가까운 구간에서 아이가 ‘봤어’라고 하면 설명이 자동으로 시작됩니다.
5. 설명 재생을 마치면 처음 생각과 비교하는 질문이 이어집니다. 음성 재생이 불가능하면 비교 버튼으로 진행할 수 있습니다.
6. ‘비슷했어 / 달랐어 / 아직 모르겠어’ 중 자신의 발견을 남깁니다. 정답 점수나 오답 판정은 없습니다.

5분은 최종 목적지가 아닌 각 관찰 지점까지의 ETA를 기준으로 합니다. ‘통과’와 ‘직접 봄’은 구분하며 위치만으로 실제 시야를 판단하지 않습니다.

## 체험

앱에서 **시연 여행 시작**을 누릅니다. 숭례문과 광화문을 예시로 한 가상 서울 경로가 시간10배로 진행됩니다. 시작 후 약6초면 첫 질문, 약33초면 관찰 안내, 약37초면 통과 설명이 나옵니다. 아이가 먼저 ‘봤어’를 선택하면 설명이 더 일찍 시작됩니다.

보호자 → 시점 이동해서 확인에서 5분 전, 근처, 통과 신호를 수동으로 넣어 빠르게 확인할 수 있습니다. ‘말 대신 입력’으로 예상을 입력할 수도 있습니다. 입력과 마이크 듣기를 열면 시연이 잠시 멈춥니다. 보호자 메뉴에서 이어서 재생합니다.

- 숭례문: 옛날 도시에 왜 커다란 문이 필요했을까?
- 광화문: 문 뒤에 어떤 공간이 있을까?
- 반복 위치 신호에도 질문과 설명은 한 번씩만 재생합니다.
- 경로에서 빠진 예정 지점은 취소하며, 이미 설명 중인 이야기를 다음 명소가 끊지 않습니다.
- 쉬기, 건너뛰기, 답하지 않기가 가능합니다.

## 실제 내비게이션 연결의 범위

NaviHelper3.0.5 SDK와 읽기 권한 NAVI_ROUTE를 연결했습니다. 보호자 → 실제 내비게이션 연결 확인에서 목적지 조회를 요청합니다. 경로 변경과 취소 이벤트도 처리합니다. 목적지와 위치는 서버에 보내거나 기기에 저장하지 않습니다. 내비게이션 설정, 목적지 변경 또는 우회 경로 요청은 하지 않습니다.

현재 전체 체험은 **가상 경로와 지점별 ETA 제공자**로 동작합니다. 다음은 아직 실제 운행과 연결되지 않았습니다.

- 실제 선택 경로를 따라 모든 역사 명소와 랜드마크를 자동 검색하는 기능.
- 각 명소의 관찰 가능 구간과 지점별 ETA 계산.
- 실제 경로 재탐색 결과를 큐레이터의 지점 목록으로 변환하는 제공자.
- 실차에서의 자동 통과 판정과 차창 가시성 검증.

공식 SDK의 목적지 도착 시간이나 주변 직선거리만으로 명소까지의 도착 시간을 만들어내지 않습니다. 실제 연결 화면에서는 준비 중임을 표시하며 시연 데이터와 혼합하지 않습니다.

기존 차량 UI와 운전자 주의 분산 제한은 유지합니다. 현재 버전은 정차 시연용이며 주행 중 승객용 화면과 음성 동작에 대한 차량 정책 검증은 별도 작업입니다.

## 내용과 개인정보

숭례문은 국가유산청 궁능유적본부, 광화문은 정부 정책브리핑 자료를 바탕으로 직접 쓴 짧은 설명입니다. 생성형 AI로 역사 사실을 즉석에서 만들지 않습니다. 앱의 보호자 → 설명 출처에 원문 링크가 있습니다.

시연 기억에는 명소 ID, 미리 제공한 선택 답변, 관찰 여부와 비교 결과만 저장합니다. 자유롭게 말한 예상은 실행 중에만 표시하고 저장할 때 ‘자유롭게 생각했어’로 바꿉니다. 답하지 않았다면 ‘답하지 않았어’로 남깁니다. 녹음과 위치, 원문 전체는 저장하지 않고 외부 AI를 호출하지 않습니다. 이전 API 키나 중계 서버 설정도 변경하지 않았습니다.

## 코드

- domain/RouteCurator.kt: 경로 신호를 받는 순수 상태 처리, 지점별 5분 전 질문과 자동 설명, 예상과 회상.
- MainActivity.kt: 새 큐레이터 화면, 음성, 정차 시연과 보호자 기능.
- CuratorSceneView.kt: 직접 그린 문 형태와 단계 표시, 700ms 교차 페이드.
- CuratorNaviSource.kt: 공식 NaviHelper 목적지 조회와 수명 관리.
- CloudLegacyActivity.kt 및 이전 엔진: 이전 버전 구현 보존. 실행 화면과 연결하지 않습니다.

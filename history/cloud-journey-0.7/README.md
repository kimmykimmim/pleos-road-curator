# 구름 친구 — Pleos 프로토타입 0.7

빈 하늘에서 시작합니다. 아이가 구름에서 떠올린 모습을 말하면 그 모양이 3D 친구로 태어납니다. 다음 구름은 친구로 만들거나 얼굴 없는 배경으로 하늘에 띄울 수 있습니다. 먼저 만든 친구와 구름은 함께 남으며, 선택한 친구와 오늘의 일상을 이야기합니다.

## 놀이 흐름

1. **하늘 만나기**를 누릅니다. 아직 캐릭터와 배경 구름은 없습니다.
2. “오늘은 뭐가 기대돼?”에 답하거나 **구름부터 볼래**로 건너뜁니다. “할머니 만나는 게 기대돼”는 정확한 장소 대신 ‘가족 만나기’로만 남습니다. 바로 구름 모양을 말해도 됩니다.
3. **이야기하기**를 켜고 “저 구름 토끼 같아”라고 말하면 토끼가 서서히 태어나 인사합니다.
4. 일상 이야기를 나누다가 다른 구름이 눈에 들어오면 알려줍니다.
5. “저쪽 구름은 고래 같아” → **친구로 만들자** 또는 **하늘에 띄우자**를 말하거나 누릅니다.
6. 친구를 여러 명 만들었다면 이름 버튼을 누르거나 “토끼랑 이야기할래”라고 말해 대화 상대를 고릅니다.
7. “이거 기억할래” 또는 **이 순간 남기기**로 방금 다룬 구름을 오늘의 기억으로 고릅니다. “고래 구름 기억해줘”처럼 특정 구름을 말해도 됩니다.
8. **여행 마치기**에서 기대했던 활동과 내가 고른 구름을 함께 돌아봅니다. 아직 고르지 않았다면 이때 선택하거나 그대로 두어도 됩니다. 새 여행은 다시 빈 하늘로 시작하고 지난 하늘은 보호자 메뉴에 남습니다.

정해진 발견 순서나 점수는 없습니다. 아무 모양도 떠오르지 않거나 구름이 보이지 않으면 쉬어도 됩니다. 아직 친구를 만들지 않은 상태에서는 안내만 제공하고 가상의 친구가 먼저 말을 걸지 않습니다.

## 오늘의 이동을 기억하는 흐름

이번 버전의 기억은 **기대했던 활동 → 길에서 만난 구름 → 아이가 고른 대표 장면 → 도착 후 다시 보기**로 이어집니다. 예를 들어 ‘가족을 만나러 가던 날’의 하늘 안에 토끼 친구와 고래 구름이 함께 있고, 아이가 고래를 기억으로 골랐다면 그 선택이 따로 표시됩니다. 앱이 좋아할 만한 순간을 임의로 선정하지 않습니다.

활동 종류는 가족 만나기, 즐겁게 놀기, 새로운 곳 만나기 세 가지입니다. 말한 문장 전체나 정확한 행선지를 기록하지 않습니다. 현재 기억 선택 대상은 만들어진 구름이며, 터널이나 빛의 변화를 자동 감지해 장면으로 남기는 기능은 아직 없습니다. 출발과 도착은 버튼 또는 발화로 진행합니다.

## 부드러운 전환

- 말 한마디마다 3D 화면을 새로 만들던 동작을 제거하고 같은 화면을 계속 유지합니다.
- 새 구름은 약 0.82초 동안 투명한 상태에서 선명해지며 살짝 커집니다.
- 미리보기를 친구로 고르면 같은 구름이 앞으로 이동하며 얼굴이 나타납니다. 배경으로 고르면 얼굴 없이 옆으로 자리 잡습니다.
- 대화 상대를 바꾸면 두 친구가 서로 비켜 가는 경로로 위치와 크기를 바꿉니다.
- 모양 정정과 되돌리기는 이전 모습과 다음 모습의 투명도를 교차하며 바뀝니다.
- 전환 중 다시 입력하면 화면에 보이던 중간 위치부터 새 전환을 이어갑니다.
- 대화 카드는 짧게 사라졌다 나타납니다. 시스템에서 애니메이션을 꺼 두었으면 최종 상태를 바로 적용합니다.
- 각 구름 전체를 따로 그린 뒤 투명도를 적용해, 사라지는 동안 몸을 구성하는 도형들이 서로 비쳐 보이지 않도록 했습니다.

## 말 대신 확인하기

보호자 → 말 대신 입력해 보기에서 예시를 누르거나 직접 입력합니다. 문자와 음성은 같은 처리 경로를 사용합니다.

| 입력 | 화면과 대화 |
| --- | --- |
| 저 구름 토끼 같아 | 첫 토끼 친구 탄생, 오늘의 일을 묻는 인사 |
| 오늘은 공원에서 놀 거야 | 친구와 일상 대화, 구름 모양은 그대로 |
| 저쪽 구름은 고래 같아 | 고래 모양 미리보기와 역할 선택 |
| 하늘에 띄우자 | 토끼 친구를 유지하고 고래 배경 구름 추가 |
| 공룡 구름을 친구로 만들어줘 | 새로운 공룡 친구 추가, 대화 상대 전환 |
| 토끼랑 이야기할래 | 원래 토끼 친구와 다시 대화 |
| 이름은 뭉치야 | 선택한 친구에게만 이름 붙이기 |
| 그거 고래가 아니라 공룡이야 | 마지막으로 다룬 구름 모양 교정 |
| 오늘 고래 인형을 갖고 놀 거야 | 새 구름을 만들지 않고 일상 이야기로 처리 |
| 고래 구름 기억해줘 | 대화 상대는 유지하고 고래를 오늘의 기억으로 선택 |
| 기억에서 빼줘 | 대표 기억 선택을 취소하고 구름은 유지 |

## 실제 구현 범위

- Pleos 운전 화면과 공조 바는 유지하며 앱 영역만 변경합니다.
- 구름의 모양은 아이가 말한 내용을 바탕으로 해석합니다. 하늘 카메라, 자동 시각 인식, GPS, 시선 감지는 연결하지 않았습니다.
- 실제 3D 도형, 조명과 깊이로 그립니다. 친구에게는 얼굴이 있고 배경 구름에는 얼굴이 없습니다. 선택한 친구만 말할 때 입을 움직입니다.
- 토끼, 고래, 공룡, 용, 강아지, 고양이, 거북이, 새, 빵, 배, 하트와 기본 구름 형태를 지원합니다. 알려지지 않은 모양은 이름 붙인 몽실한 구름으로 표현합니다. 임의의 말에서 정확한 새 3D 모형을 생성하는 방식은 아닙니다.
- 한 하늘에는 최대 8개를 보관합니다. 이는 시연 구현의 크기 제한이며 놀이 목표나 수집 점수가 아닙니다.
- 모양과 특징, 친구 또는 배경 역할, 별명, 선택한 친구, 기대하는 활동 종류와 대표 기억을 저장합니다. 역할 선택 중인 임시 구름과 답변 대기 상태는 다시 실행할 때 남기지 않습니다.
- 0.6의 하늘은 유지하고 새 항목을 선택적으로 추가합니다. 더 이전 풍경 친구 저장소도 삭제하지 않습니다.

## 자유 대화 연결

AI 모드에서는 기기에서 인식한 문자, 최근 12개 대화와 현재 선택된 친구의 모습, 하늘 구성, 기대하는 활동 종류 및 고른 기억이 로컬 서버를 통해 OpenAI로 전달됩니다. 대화 상대를 바꾸거나 새 여행을 시작하거나 앱이 배경으로 이동하면 최근 대화를 비웁니다. 녹음 파일과 대화 문장 전체를 저장하지 않습니다.

1. PC의 안전한 설정 파일 `.env.local`에 `OPENAI_API_KEY`를 준비합니다. 키는 APK와 소스 묶음에 포함하지 않습니다.
2. 프로젝트 폴더에서 `node --env-file-if-exists=.env.local server/local-companion.mjs`로 로컬 서버를 실행합니다.
3. 에뮬레이터에 `adb reverse tcp:8791 tcp:8791`을 적용합니다.
4. 앱에서 **보호자 → AI 자유 대화 연결**을 켭니다.
5. 구름 친구가 태어난 뒤 오늘의 이야기를 나눕니다. 마이크는 별도로 직접 켜야 합니다.

서버는 `127.0.0.1:8791`에만 열립니다. 실제 차량의 독립 실행 배포 구성이 아닌, PC와 연결한 에뮬레이터 시연 구성입니다. 키가 없거나 연결을 끈 상태에서는 기기 내 짧은 규칙 대화를 사용합니다. 연결 오류를 AI 답변처럼 대신 꾸며 내지 않습니다.

현재 외부 AI 연결은 **성인이 만든 가상 예시용**입니다. 실제 13세 미만 아동의 개인정보를 처리하기 전에는 ZDR[API 데이터 무보관 설정] 요구사항 확인이 필요합니다. `store:false`만으로 ZDR이 적용되지 않습니다. 실제 연결 확인 결과와 이번 키의 유효기간은 `VALIDATION.md`에 기록합니다.

## 중단과 음성

- Pleos TTS/STT 3.3.1의 기기 내 음성을 유지합니다. 말하기가 끝난 뒤 최소 600ms 후 듣기를 시작합니다.
- 쉬기, 대화 끄기, 여행 마치기, 메뉴 열기, 앱의 배경 이동과 차량 제한에서 듣기와 기다리던 답변을 취소합니다.
- 말이 없으면 듣기를 마칩니다. 다시 이야기할 때 버튼을 누릅니다.
- 차량의 주행 중 사용 제한을 따르는 정차 시연 버전입니다.

## 개발 파일

- `domain/CloudPlayEngine.kt`: 빈 하늘, 모양 해석, 친구와 배경 역할, 선택과 교정
- `CloudWorldStore.kt`: 현재 하늘과 지난 여행 저장
- `LandscapeFriend3DView.kt`: 여러 구름의 실제 3D 표시와 선택한 친구의 표정
- `rendering/CloudSceneMotion.kt`: 연속적인 페이드와 위치, 크기, 얼굴 전환
- `MainActivity.kt`: 차량 앱 화면과 음성, 문자, AI 연결
- `network/FriendChatClient.kt`: API 키를 넣지 않은 로컬 서버 연결
- `network/AsyncReplyGate.kt`: 취소된 답변 차단
- `server/local-companion.mjs`: 선택한 구름 친구의 일상 대화

Android API 34, Build Tools 36.0.0, AGP 9.1.0, Gradle 9.3.1, 빌드 JDK 21을 사용합니다.

# 구름 친구 0.7 확인 결과

- 확인일: 2026-11-09
- 대상: Pleos Connect v2.1.0, Android API 34, x86_64, 사용자 10
- 설치 버전: 0.7.0, versionCode 7, 패키지 dev.changbak.explorer

## 이번 변경

- 같은 3D 화면을 유지하면서 상태를 갱신합니다. 대화나 선택마다 GL 화면을 없애고 새로 만들지 않습니다.
- 약 820ms 동안 구름의 투명도, 크기, 위치와 얼굴을 연결합니다. 미리보기에서 선택한 친구로 이동할 때 하나의 구름으로 이어지고, 상대를 바꿀 때 두 친구가 비켜 지나갑니다.
- 각 구름을 별도 버퍼에 완전히 그린 뒤 투명도를 합성합니다. 몸을 구성하는 겹친 도형이 서로 비치는 현상을 피합니다.
- 대화 카드는 110ms 동안 사라지고 210ms 동안 나타납니다. 배경 이동과 종료 시 오래된 전환 콜백을 취소합니다.
- 새 여행에서 기대하는 활동을 선택적으로 말할 수 있습니다. 바로 구름을 묘사하거나 건너뛰어도 됩니다.
- ‘이거 기억할래’와 ‘이 순간 남기기’로 아이가 대표 구름을 직접 고릅니다. 도착 화면은 활동 제목과 고른 구름을 함께 보여줍니다.
- 정확한 행선지와 문장 전체 대신 가족 만나기, 즐겁게 놀기, 새로운 곳 만나기 중 활동 종류만 저장합니다.

## 검증

1. testDebugUnitTest assembleDebug assembleDebugAndroidTest 빌드가 성공했습니다. 단위 검사 122개가 모두 통과했고 실패, 오류, 생략은 0개입니다.
2. 전환 검사에는 생성 중간 투명도, 미리보기의 동일성, 얼굴 없는 배경, 두 친구의 위치 교환과 서로 비켜 가는 경로, 전환 중 재입력, 모양 교정, 되돌리기와 애니메이션 비활성화를 포함합니다.
3. 에뮬레이터의 실제 GLES 그리기 코드로 빈 하늘, 친구 생성, 배경, 여러 친구와 선택을 검사했습니다. 얼굴 색 픽셀은 친구 472개, 배경 0개였습니다.
4. 별도 검사 전용 저장소에서 활동 종류와 선택한 대표 기억의 복원을 확인했습니다. 새 여행을 시작해도 지난 하늘이 남으며, 임시 역할 선택과 듣기 상태는 복원하지 않습니다.
5. 실제 그리기 코드로 전환 단계 84개와 정지 장면을 포함해 134개 PNG를 생성했습니다. 구름 탄생, 미리보기 등장, 친구로 변하며 얼굴이 나타나는 이동, 대화 상대 교환 모두 PASS입니다.
6. 구름 탄생의 0%, 25%, 50%, 75%, 100% 장면에서 배경과의 색 차이 합계가 0 → 609373 → 2122832 → 3934457 → 4878394로 점진적으로 증가했습니다. 시작부터 완성 모습으로 갑자기 바뀌지 않았습니다.
7. 중간 그림을 직접 확인하고 두 친구가 겹치던 경로를 수정했습니다. 수정 후 중간 위치가 분리된 그림과 전체 전환 검사를 다시 확인했습니다.
8. 최종 앱을 업데이트 설치하고 topResumedActivity, 버전 0.7.0, 셰이더 컴파일과 첫 3D 프레임을 확인했습니다. 기존 저장된 구름 2개가 유지됐으며 해당 앱의 시작 기록에 치명적 예외가 없었습니다.

## 예시 영상

preview/cloud-transitions.mp4는 위 134개 검사 그림을 25fps로 묶은 약 5.36초의 영상입니다. 실제 앱과 같은 3D 도형과 합성 코드를 사용하며, 전체 차량 화면을 녹화한 영상은 아닙니다. 반복 확인을 위해 각 단계 사이에 잠시 멈추는 장면을 넣었습니다. 실제 전환은 약 0.82초입니다.

## 연결과 남은 확인

- 자유 대화 서버와 API 연결 방식은 0.6과 동일합니다. 이번 변경에서 추가 API 키를 생성하거나 설정 파일을 바꾸지 않았습니다. 직전 버전에서 성인의 가상 입력으로 실제 OpenAI 응답을 확인했습니다.
- 이번 키는 생성 후 24시간 유효하도록 사용자가 선택했습니다. AI 대화는 보호자 메뉴에서 켭니다.
- 실제 아동 개인정보 처리를 위한 ZDR은 확인되지 않았습니다. 외부 AI는 성인의 가상 예시용입니다.
- 실제 마이크, 스피커 소리, 전체 화면의 터치 흐름과 장치별 프레임 속도는 직접 검증하지 않았습니다. Windows 화면 조작 도구의 기존 초기화 경로 오류가 남아 있습니다.
- 실제 하늘, 터널, 빛과 도착을 자동 감지하지 않습니다. 현재 대표 기억의 대상은 아이가 만든 구름이며, 출발과 도착은 버튼 또는 말로 진행합니다.
- 실제 차량의 주행 전환과 탑승자 표시 위치는 별도 검증 대상입니다. 현재는 차량 사용 제한을 따르는 정차 시연 버전입니다.

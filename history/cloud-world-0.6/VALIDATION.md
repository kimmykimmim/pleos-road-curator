# 구름 친구 0.6 확인 결과

- 확인일: 2026-11-09
- 설치 대상: Pleos Connect v2.1.0, Android API 34, x86_64, 사용자 10
- 패키지: dev.changbak.explorer, versionCode 6, versionName 0.6.0
- 실제 Pleos 운전 화면과 공조 바를 유지하고 앱만 업데이트했습니다.

## 확인 완료

1. 전체 빌드와 Android 단위 검사 107개가 통과했습니다. 실패, 오류, 생략은 모두 0개입니다. 빈 하늘, 첫 친구, 배경 역할, 여러 친구, 이름, 정정, 취소, 일상 대화 구분 검사 19개를 새로 포함합니다.
2. 서버 모의 검사 16개가 통과했습니다. API 키 없는 모의 응답으로 접근 제한, 요청 형식, 대화 기록 분리, 검토, 시간 초과와 취소를 확인했습니다.
3. 에뮬레이터에서 실제 앱과 동일한 3D 그리기 코드를 실행해 여섯 개 그림을 생성했습니다. 빈 하늘, 토끼 친구, 고래 배경 추가, 두 친구와 배경, 대화 상대 선택, 얼굴 없는 배경이 PASS입니다. 빈 하늘에는 도형이 없고 토끼 친구의 얼굴 색 픽셀은 465개, 배경 구름의 얼굴 색 픽셀은 0개였습니다.
4. 별도의 검사 전용 저장소에서 저장과 복원을 확인했습니다. 친구와 배경 역할, 선택한 친구가 유지되고 임시 역할 선택은 복원되지 않으며, 새 여행을 시작해도 지난 하늘 보관본이 남습니다. 실제 사용자 저장소는 검사에서 읽거나 지우지 않았습니다.
5. 합성 예시로 실제 OpenAI 응답을 확인했습니다. “오늘은 공원에서 놀 거야. 너는 어떤 구름이었어?”에 공원 이야기를 받아 주고, 선택된 토끼 친구가 토끼 모양 구름에서 태어났다고 답했습니다. 배경 고래를 자신의 정체로 혼동하지 않았습니다.
6. 업데이트 후 앱의 topResumedActivity와 버전 0.6.0을 확인했습니다. 실제 실행 기록에서 첫 3D 프레임의 cloudCount=0을 확인했고 치명적 예외가 없었습니다.
7. 여섯 개 그리기 검사 그림 중 첫 친구, 배경 추가, 여러 친구 그림을 직접 열어 형태와 배치를 확인했습니다.

## 연결과 데이터

- PC의 로컬 서버는 127.0.0.1:8791이며 에뮬레이터의 adb reverse 연결을 유지했습니다.
- API 키는 승인된 프로젝트의 .env.local에만 있습니다. 앱, 소스 묶음과 화면에 포함하지 않습니다. 이번 키는 생성 후 24시간 유효하도록 사용자가 선택했습니다.
- 새 버전은 기본으로 기기 내 대화를 사용합니다. 보호자 → AI 자유 대화 연결에서 성인 가상 시연 조건을 확인하면 외부 대화를 사용할 수 있습니다.
- 실제 아동의 개인정보 처리를 위한 ZDR은 확인되지 않았습니다. 외부 대화는 성인이 만든 가상 예시로만 검사했습니다. store:false와 ZDR은 다릅니다.
- 0.6은 cloud_world_v1 저장소를 사용합니다. 이전 landscape_friends_v1은 삭제하지 않고 첫 화면에서 불러오지도 않습니다.

## 남은 범위

- 실제 마이크 인식률, 스피커 소리, 전체 차량 화면과 모든 터치 동작은 직접 검증하지 않았습니다. Windows 화면 조작 도구의 기존 초기화 경로 오류가 남아 있습니다.
- 그림은 화면 없는 EGL 버퍼에서 만든 앱의 3D 결과이며 전체 차량 화면의 캡처가 아닙니다.
- 실제 하늘 자동 인식과 자유로운 3D 모델 생성은 없습니다. 준비된 모양을 표현하고 낯선 형태는 이름 붙인 몽실한 구름으로 표시합니다.
- 실제 차량의 주행 전환과 탑승자 표시 위치는 검증하지 않았습니다. 현재는 차량 사용 제한을 따르는 정차 시연 구성입니다.

# 개발 환경과 실행

## 프로젝트 열기

- 이 인계 폴더 안의 `native-app`을 Android Studio로 엽니다.
- IDE가 Android SDK 위치를 정하도록 합니다. 원본 PC에만 맞는 `local.properties`는 제외했습니다.
- Gradle 실행 파일과 wrapper JAR는 포함되어 있습니다.
- 최초 빌드는 인터넷에서 Android 및 Pleos 의존성을 받아야 합니다.
- 원본 PC는 JDK 21.0.10을 사용했습니다. Kotlin과 Java의 대상 바이트코드는 17입니다.
- 컴파일 SDK 34, build tools 36.0.0, minSdk 28, targetSdk 34입니다.
- Pleos Connect v2.1.0 에뮬레이터에서 확인했습니다.

## 빌드 흐름

1. Android Studio에서 SDK와 JDK 경로를 확인합니다.
2. `native-app`에서 빌드와 검사를 실행합니다.
3. APK를 Pleos 에뮬레이터에 설치합니다.
4. 정차 상태에서 앱을 엽니다.
5. `실제 내비로 음성 여행 시작`을 누르고 필요한 위치 권한을 허용합니다.

Windows PowerShell:

```powershell
./gradlew.bat --no-daemon --console=plain testDebugUnitTest assembleDebug assembleDebugAndroidTest
```

macOS:

```sh
chmod +x gradlew
./gradlew --no-daemon --console=plain testDebugUnitTest assembleDebug assembleDebugAndroidTest
```

- 성공 기준: 현재 인계본은 단위 검사 180개 통과입니다.
- 앱 APK: `app/build/outputs/apk/debug/app-debug.apk`
- 검사 APK: `app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk`
- 생성된 APK는 디버그 서명입니다. 다른 PC에서 빌드하면 서명이 달라져 기존 앱 위에 설치되지 않을 수 있습니다. 앱 삭제는 저장된 시연 기록을 지우므로 사용자와 범위를 확인하세요.

## 설치와 검사

아래는 `adb`가 실행 경로에 있다고 가정한 명령입니다.

```sh
adb -s emulator-5554 install -r app/build/outputs/apk/debug/app-debug.apk
adb -s emulator-5554 install -r app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb -s emulator-5554 shell am instrument --user current -w -e check navi-connection dev.changbak.explorer.test/dev.changbak.explorer.SceneRenderCheck
adb -s emulator-5554 shell am instrument --user current -w -e check curator-media dev.changbak.explorer.test/dev.changbak.explorer.SceneRenderCheck
adb -s emulator-5554 shell am instrument --user current -w -e check curator dev.changbak.explorer.test/dev.changbak.explorer.SceneRenderCheck
adb -s emulator-5554 shell am start --user current -n dev.changbak.explorer/.MainActivity
```

- `navi-connection`: 실제 공개 SDK에 조회만 합니다. 경로를 바꾸지 않습니다. 상태와 콜백 개수만 출력합니다.
- `curator-media`: 로컬 영상의 디코딩과 그림 변화 검사입니다.
- `curator`: 기기 안의 가상 위치 신호로 이야기 흐름을 검사합니다. 실제 운행 검사가 아닙니다.
- `curator-media-build`: 원본 영상용 그림 720장을 다시 생성합니다. 일반 실행에는 필요 없습니다.

## 실제 연결의 첫 확인

- 아직 원본 에뮬레이터에서 정확한 위치 권한이 허용되지 않았습니다.
- 위치 권한은 정상 앱 화면에서 요청합니다. ADB로 강제 허용한 상태를 사용자 동의라고 간주하지 마세요.
- 현재 SDK 조회에서는 `SAFE_GUIDING`이 나왔습니다. 목적지 안내 중인 상태를 추가로 만들어야 합니다.
- 지원 장소를 실제 목적지나 경유지로 설정한 뒤 `ROUTE_GUIDING` 또는 `SIMULATION_GUIDING`과 개별 남은 시간을 확인하세요.
- 현재 서비스는 화면 밖 음성 흐름을 구현했지만 실제 운행과 음성 중단 복귀 검증이 남아 있습니다.

## 외부 AI와 키

- 현재 큐레이터는 외부 AI를 호출하지 않습니다.
- `server`와 과거 캐릭터 코드는 비교와 후속 수정용으로 보관되어 있습니다.
- 기존 `.env.local`, API 키, 인증용 설정, 실행 로그는 제외했습니다.
- 이전 캐릭터 대화를 다시 켜려면 별도 설정과 사용자 확인이 필요합니다. 기존 키가 유효하다고 가정하지 마세요.

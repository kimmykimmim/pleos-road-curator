# 화면 설계 메모

`anthropics/skills`의 `frontend-design` 지침을 우리 화면에 적용하며 내린 결정을 적어 둡니다.
다음에 화면을 고칠 사람이 같은 자리를 다시 헤매지 않도록, 무엇을 왜 골랐는지와
무엇을 일부러 피했는지를 함께 남깁니다.

## 무엇에 대한 화면인가

차 뒷자리에 앉은 6~8세 아이. 안전벨트에 묶여 있고, 화면에는 손이 닿지 않습니다.
수백 번 지나친 건물을 오늘 처음으로 쳐다보게 만드는 것이 이 화면의 일이고,
따라서 화면의 목표는 **아이의 주의를 창밖에 빼앗기는 것**입니다.
화면이 주인공이 되면 실패입니다.

## 고정된 것

- 색 계열: 사용자가 준 팔레트 #086288 / #4D8DBA / #97D7FF / #FFEFC4
- 구조: 사용자가 준 참고 UI의 형태 언어 — 깊은 색 히어로, 흰 카드, 알약 버튼, 점 표시

브리프가 정한 축은 그대로 둡니다. 아래는 자유로웠던 축에서 내린 결정입니다.

## 색

| 이름 | 값 | 무엇 |
|---|---|---|
| window | `#084E6E` | 들여다보는 면. 단색 |
| ink | `#0B2D3F` | 글자 |
| daylight | `#DBEAF4` | 바탕. 팔레트의 하늘색을 글자가 앉을 만큼 밝힌 것 |
| paper | `#FFFFFF` | 카드 |
| mark | `#FFEFC4` | 팔레트의 크림. 바탕이 아니라 표시로만 |
| muted | `#46606F` | 보조 글자 |

바탕이 크림(`#FBF5E9`)이었는데 바꿨습니다. 두 가지 이유입니다.
생성형 디자인에서 가장 흔한 배경이 바로 그 색이고, 이야기가 틀렸습니다.
차 안의 아이가 보고 있는 것은 종이가 아니라 하늘과 도시입니다.

## 글자

두 서체만 씁니다. 서로 확실히 다릅니다.

- **Jua** (SIL OFL, `assets/fonts/`) — 한 패널에서 가장 큰 글자 하나에만.
  장소 이름과 시작 화면의 문장. 둥글고 아이 얼굴 같은 서체입니다.
- **시스템 산세리프** — 나머지 전부. 달리는 차에서 읽는 글은 중립적인 쪽이 낫습니다.

성격은 눈이 가장 먼저 닿는 한 군데에만 둡니다. 크기는 `MainActivity.Text`의 여섯 단계뿐입니다.

## 모양이 뜻을 가진다

| 반지름 | 무엇 |
|---|---|
| 40dp | 창. 히어로만 |
| 10dp | 종이. 카드와 보호자 화면 |
| 알약 | 누르는 것, 그리고 라벨 |

전부 같은 반지름을 쓰면 공짜로 쓸 수 있는 신호 하나를 버리는 셈입니다.
읽기 전에 그게 뭔지 알 수 있어야 합니다.

## 일부러 피한 것

`frontend-design`이 "주제와 상관없이 늘 나타나는 기본값"으로 꼽는 것들입니다.
우리가 실제로 걸렸던 것은 앞의 네 가지입니다.

- 크림 배경 → 하늘색으로
- 모든 것에 같은 반지름 → 셋으로, 각각 뜻을 가지게
- 장식용 그라데이션 → 히어로를 단색으로
- `A · B · C` 가운뎃점 조합 → 칩을 나눠서 구조로
- 제목 위의 작은 라벨 → 여정 중에는 숨김. 시작 화면에만
- 전부 대문자 라벨 → 쓰지 않음

**01 / 02 번호 마커는 남겼습니다.** 스킬은 "내용이 실제로 순서일 때만" 쓰라고 하는데,
장소 하나를 만나는 네 단계는 실제 순서입니다. 다만 번호를 동그라미로도 그리고 점으로도
그리고 있어서, 한 사실에 장치가 둘이었습니다. 동그라미를 지우고 점만 남겼습니다.

## 대담함은 한 군데에만

창입니다. 해설 단계에서는 그림이 화면 전체를 가졌다가 돌려줍니다.
나머지는 조용해야 합니다.

## 품질 바닥

- 작은 글자 대비 4.5:1 이상. `muted`를 흰 바탕 6.6:1, 바탕색 위 5.4:1로 어둡게 했습니다.
- 움직임 줄이기 설정을 존중합니다. 애니메이션이 꺼져 있으면 즉시 전환합니다.
- 긴 차례는 카드 안에서만 스크롤합니다. 페이지가 늘어나지 않습니다.

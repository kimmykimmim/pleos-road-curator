앱에서 직접 시연할 때

  1. 정차 상태에서 보호자 → 아이 설정 → 한국어와 역사를 선택합니다.
  2. 시작 화면의 도심의 오래된 이야기를 선택합니다. 숭례문 → 광화문 → 청진옥 순서입니다.
  3. 짧게 보여 줄 때는 보호자 → 시점 이동해서 확인에서 장소의 약 5분 전 / 가까이 / 통과를 고릅니다. 이 기능의 시간은 가상 신호입니다.
  4. 같은 질문을 재현하려면 보호자 → 질문을 처음 만남으로 되돌리기를 사용합니다. 실제 사용 기록도 초기화되므로 발표용 에뮬레이터에서만 필요할 때 사용하세요.
  5. 마무리 멘트: “장소 정보를 나열하는 대신, 아이가 좋아하는 분야에서 질문하고 실제 풍경을 다시 보게 합니다.”

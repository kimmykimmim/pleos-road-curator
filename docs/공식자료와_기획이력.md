# 공식 자료와 기획 이력

## 기획이 변한 흐름

- 시작: 아이가 창밖을 보게 만드는 차량 앱
- 합주: 풍경을 자기 목소리로 표현하여 음악에 반영
- 자유 이야기: 아이의 상상을 앱이 이어주는 방식
- 구름 및 풍경 친구: 관찰을 3D 캐릭터와 기억에 반영
- 차량 맥락 보강: 차가 이동하는 경로 자체를 경험으로 사용
- 현재: 경로 주변의 역사, 건축 과학, 생활사를 짧은 질문과 해설로 만나는 큐레이터
- 현재 흐름에 맞춰 네이티브 화면을 바꾸었으며 과거 웹과 캐릭터 코드 일부는 보관 중입니다.

## 자료의 성격

- 역사와 과학 해설은 위 출처에 근거한 자체 요약입니다.
- 그림과 5개 영상은 직접 작성한 Canvas 코드로 만든 설명 모형입니다.
- 외부 사진과 영상을 내려받아 재사용한 것이 아닙니다.
- `legacy-web/RESEARCH.md`는 이전 기획 때의 연구 메모입니다. 현재 네이티브 앱의 모든 설계를 최신 논문으로 검증했다는 의미는 아닙니다.
- `history` 문서는 해당 버전 시점의 상태입니다. 현재 상태는 루트 `CLAUDE.md`와 `현재상태와_다음작업.md`가 우선입니다.

## 1. 지금 상태 한 줄

여섯 장소를 지나는 고정 경로 한 개, 장소마다 그 장소의 실제 사진으로 된 설명,
뒷자리 음성 응답, 보호자가 적어 둔 가족의 기억, 서명 APK까지 동작합니다.
단위 검사 382개 통과, 기기 검사 3종 통과.

## 2. 오늘 바뀐 것 (0.35.0 → 0.40.0)

- 0.35.0 설명 화면을 도형 모형에서 **실제 사진 스크랩**으로 전면 교체. 장소 해시태그 도입,
  기억 카드에서 기록용 문장 제거.
- 0.36.0 보호자가 적어 둔 이야기 뒤에 "기억나지 않아도 괜찮아"를 붙이지 않음.
  상상 놀이라는 말을 "여기부터는 네가 만드는 이야기야"로 교체.
- 0.37.0 실제 내비 대기 화면의 글을 네 문단에서 한 줄로.
- 0.38.0 멈춤 버튼을 "그만 들을래" / "다시 들을래"로.
- 0.39.0 Codex 아이 관점 점검 C01 C02 C03 C05 C06 C07 수정 (C04는 미결).
- 0.40.0 설명 사진을 **장소별**로 분리(숭례문/광화문이 경복궁 사진을 나눠 쓰던 문제),
  63빌딩은 1984년 + 지금 유리 외벽, 설명 영상 6개(장소별), 질문 옆 작은 그림을
  장소 기준으로 선택, 고정 경로를 여섯 곳으로 확대.

## 3. 고정 경로

`CuratorRoutes.fixed` = 롯데월드타워 → 63빌딩 → 여의도 → 숭례문 → 광화문 → 청진옥.
앞 세 곳이 과학(구조, 커튼월, 매립), 뒤 세 곳이 역사와 생활. `passageAt(i) = 360 + i*720`,
시연은 10배속. 경로 막대(RouteRule)는 장소 수에 맞춰 자동으로 나뉩니다.

## 4. 사진과 출처

`native-app/app/src/main/assets/scenes/` 11장, 모두 자유 이용 허락.
촬영자와 라이선스는 화면에도 나오고 `scenes/README.md`, `scenes/sources.json`에 정리.
장소마다 그 장소 사진만 쓰며, 가족 장소에는 사진을 넣지 않습니다.

## 5. 남은 일 (우선순위)

1. **UI 색감 선택 대기.** 제안 5안을 `validation/ui-proposals/ui-a..e.png`로 만들어
   사용자에게 보여 준 상태. 사용자가 고르면 그 색으로 전체 적용.
   현재 색은 `MainActivity.kt`의 `ink/accent/muted/cream/onHero` 등 상수에 모여 있습니다.
2. **C04(관찰 단계에서 사진이 커서 창밖 대신 화면으로 답할 수 있음)** 판단 대기.
   선택지: 그대로 / 관찰 때만 사진 축소 / 관찰 때 사진 흐리게.
3. **시연 영상 재촬영.** `validation/clips/`의 기존 클립은 0.34.0 이전 화면이라 낡았습니다.
   녹화: `adb shell screenrecord --time-limit N --bit-rate 8000000`, 시간 제한이 지난 뒤에 pull.
   자르기: `ffmpeg -vf "crop=1682:1210:853:90,scale=760:-2,fps=12" -crf 32`.
4. **발표자료(`docs/발표자료.html`)의 화면 캡처 갱신.**
5. 미검증으로 남은 것: 실제 주행에서의 5분 전 안내, 실제 아이 음성 STT, 오디오 청취 품질.

## 6. 작업 방법 메모

- 빌드: `JAVA_HOME=~/dev/toolchain/jdk-21.0.13+9/Contents/Home ANDROID_HOME=/opt/homebrew/share/android-commandlinetools ./gradlew ...`
- 기기 검사: `adb shell am instrument -w -e check <curator|curator-media|stickers|curator-media-build> dev.changbak.explorer.test/dev.changbak.explorer.SceneRenderCheck`
- 설명 영상 재생성: `curator-media-build`로 프레임을 뽑고
  `adb exec-out "run-as dev.changbak.explorer --user 10 tar -c -C files curator-media-build"`로 받은 뒤
  `ffmpeg -framerate 24 -i frame-%03d.png -c:v libx264 -pix_fmt yuv420p -crf 23` 로 `res/raw/curator_<mediaKey>.mp4`.
- 에뮬레이터 앱 영역: `Rect(853,90 - 2535,1300)`. 스크린샷은 2560x1440.
- `adb shell input text`로는 한글을 넣을 수 없습니다. 보호자 기록 같은 한글 데이터는
  `shared_prefs` 파일을 직접 써서 넣었습니다(가족 기록 데모 문장이 영어로 남아 있던 원인).
- 서명 키는 Drive의 `signing-private`에만 있습니다. 저장소에는 올리지 않습니다.

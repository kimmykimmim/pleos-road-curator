# 창밖 탐험

6~8세 차량 동승자를 위한 관찰 미션 프로토타입입니다. 짧은 미션을 먼저 들려주고 실제 창밖을 살펴보게 하는 흐름으로 바꿨습니다.

## 아이의 흐름

- 탐험 시작 → 음성 미션 듣기 → 창밖 살펴보기
- 찾았어 → 같은 대상의 특징을 한 번 더 관찰 → 새 미션
- 안 보여 → 다른 미션. 두 번 이어지면 더 쉬운 관찰
- 지나갔어 → 현재 보이는 풍경을 살필 새 미션
- 비교 미션에서는 달라졌어와 비슷해 모두 정상적인 관찰 응답
- 쉬기 → 마이크와 안내 중단 → 준비되면 재개
- 잘못 눌렀다면 상단 되돌리기 또는 음성으로 직전 응답 취소

22개 기본 미션이 있으며 특정 나무, 차, 터널 순서로 진행하지 않습니다. 최근 네 기본 미션은 반복을 피하고 가능하면 관찰 주제를 바꿉니다. 한 대상의 자세히 보기는 연속으로 한 번까지만 제공합니다.

## 화면과 음성

- 차량 영역, 상단 상태 표시줄, 하단 검은 공조 바를 유지했습니다.
- 가운데는 탐험 안내와 발견 기록, 오른쪽은 미션 한 개와 큰 응답 버튼입니다.
- 화면에 정답을 찾는 게임이나 빠르게 누르는 점수와 제한 시간은 없습니다.
- 기본적으로 미션을 읽고 기다립니다. 약 25초 뒤 도움을 한 번 줄 수 있지만 미션을 자동으로 넘기거나 실패 처리하지 않습니다.
- 음성 알림을 켜면 미션을 읽은 뒤 찾았어, 안 보여, 지나갔어, 비슷해, 달라졌어, 힌트, 쉬자 같은 짧은 말을 받습니다.
- 실제 변화 발견과 대상이 지나간 경우를 구분합니다.
- 조용히 있거나 말을 알아듣지 못할 때 재시도는 두 번으로 제한하고 이후 자동 듣기를 멈춥니다.
- 설정을 열거나 탭을 숨기면 모든 안내, 마이크, 예약된 힌트를 중단합니다.

## 보호자가 알려주는 환경

두루 살피기, 도시, 자연, 터널, 밤 중에서 선택할 수 있습니다. 해당 환경에 맞는 미션을 고릅니다. 실제 차량이 풍경을 자동으로 인식하지는 않습니다. 환경을 바꾸어도 성공 기록을 만들어내지 않습니다.

찾았어는 아이의 자기보고입니다. 시선이나 실제 관찰 성공을 판정하지 않습니다.

## 데이터와 연결

- 이 버전은 AI API 키 없이 실행됩니다. 모델 호출과 이야기 생성 API를 사용하지 않습니다.
- 음성 알림은 보호자가 전송 안내를 확인하고 켠 뒤에만 시작합니다.
- 음성 인식에는 브라우저 제공자의 서비스가 사용될 수 있습니다. 앱은 녹음 파일을 만들거나 별도 서버에 관찰 기록을 저장하지 않습니다.
- 미션 진행과 발견 기록은 탭 메모리에만 있고 새로고침하면 사라집니다.
- 차량 그래픽과 공조 바는 예시이며 실제 차량을 제어하지 않습니다.
- 이전 이야기 실험의 소스는 현재 실행 경로와 공개 자산 목록에서 제외했습니다.

## 실행

Node.js 22 이상에서 외부 패키지 설치 없이 실행합니다.

```text
node scripts/dev.mjs --port 4173
node --test tests/mission-engine.test.mjs tests/mission-voice.test.mjs tests/voice.test.mjs tests/worker.test.mjs
node build.mjs
```

개발 서버는 http://127.0.0.1:4173 에만 연결합니다. 환경 파일을 읽지 않습니다. 배포 빌드는 공개 자산 11개를 포함하는 단일 Worker를 만듭니다. 기존 Site의 project_id와 비공개 접근 범위를 유지합니다.

## 검증

- 미션 선택, 반복 회피, 발견 후속, 두 번 못 찾은 경우, 환경 변경, 비교 응답과 기록 제한
- 음성 명령의 부정 표현, 변화와 지나감 구분, 직전 응답 취소, 중복 방지
- 명시적으로 켜기 전 마이크 미사용, 안내 중 자기 음성 인식 방지, 재시도 제한, 탭 숨김과 쉬기
- 공개 파일 경로, 폐기한 API의 404 응답, 빌드된 자산과 원본 일치
- 브라우저 제어가 설정에서 비활성화되어 새 화면의 시각 검증과 실제 마이크는 미검증
- 아동의 창밖 관찰 증가와 실제 차량 사용성은 별도 평가가 필요
